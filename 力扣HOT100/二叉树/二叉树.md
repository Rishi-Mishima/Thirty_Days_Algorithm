```java
void dfs(TreeNode root) {
```

### BFS基础遍历

```java
void bfs(TreeNode root) {
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.add(root);
    while (!queue.isEmpty()) {
        TreeNode node = queue.poll(); // Java 的 pop 写作 poll()
        if (node.left != null) {
            queue.add(node.left);
        }
        if (node.right != null) {
            queue.add(node.right);
        }
    }
}
```

层序遍历: 二维数组

- 我们 **无法区分队列中的结点来自哪一层**
- 因此，我们需要稍微修改一下代码，在每一层遍历开始前，先记录队列中的结点数量 *n*（也就是这一层的结点数量），然后一口气处理完这一层的 *n* 个结点

```java
// 二叉树的层序遍历
void bfs(TreeNode root) {
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.add(root);
    while (!queue.isEmpty()) {
        int n = queue.size();
        for (int i = 0; i < n; i++) { 
            // 变量 i 无实际意义，只是为了循环 n 次
            TreeNode node = queue.poll();
            if (node.left != null) {
                queue.add(node.left);
            }
            if (node.right != null) {
                queue.add(node.right);
            }
        }
    }
}
```

可以看到，在 while 循环的每一轮中，都是将当前层的所有结点出队列，再将下一层的所有结点入队列，这样就实现了层序遍历。

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>(); // 1. 用于保存最终按层分组的结果
  // List<List<Integer>> - 因为二叉树的层序遍历需要返回的是 “按层分组” 的结果，而不是一个扁平的一维列表。

    Queue<TreeNode> queue = new ArrayDeque<>(); // 2. 创建辅助队列
    if (root != null) {
        queue.add(root);                        // 3. 特判：根节点不为空时入队，开启 BFS
    }

    while (!queue.isEmpty()) {                  // 4. 当队列不为空，说明还有待处理的节点
        int n = queue.size();                   // 5. 关键点：获取【当前层】的节点个数
        List<Integer> level = new ArrayList<>();// 6. 用于存放【当前层】所有节点的值

        for (int i = 0; i < n; i++) {           // 7. 精确循环 n 次，只处理当前层的节点
            TreeNode node = queue.poll();       // 8. 节点出队
            level.add(node.val);                // 9. 将节点值存入当前层列表

            // 10. 将下一层的子节点依次入队（按从左到右的顺序）
            if (node.left != null) {
                queue.add(node.left);
            }
            if (node.right != null) {
                queue.add(node.right);
            }
        }
        res.add(level);                         // 11. 将收集好的当前层结果加入最终列表
    }

    return res;                                 // 12. 返回遍历结果
}
```

核心思想: 

> - **核心数据结构**：使用 **队列（`Queue`）**，遵循 **先进先出（FIFO）** 的原则。
> - **分层处理机制**：在进入每一层的循环时，通过 `int n = queue.size()` **提前记录当前层的节点总数**。这一步是把“按层分组”和“普通 BFS”区分开的关键，保证了内层 `for` 循环只处理属于当前层的节点。



## 199. 二叉树的右视图 

### 解法1: BFS

套用102题BFS的模板, 把每一层的最后一个节点值保存到答案中

- 前置题目: [102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/?envType=study-plan-v2&envId=top-100-liked)



核心解题思路

> 当你从右边看一棵树时，**每一层你只能看到最右边的那个节点**。因此，解答思路非常直接：
>
> 1. **进行标准层序遍历（BFS）**，一层一层地处理节点。
> 2. 在处理每一层时，找到**该层的最后一个节点**（即最右侧节点）。
> 3. 把这个节点的值加入结果集 `List<Integer>`。

### 

```java
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) {
            return res;
        }

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.add(root);

        while (!queue.isEmpty()) {
            int n = queue.size(); // 当前层的节点个数 
          // 快照：此时队列里装的，百分之百“全都是”且“只有”当前层的节点！

            for (int i = 0; i < n; i++) {
                TreeNode node = queue.poll(); 

                // 关键点：如果是当前层的最后一个节点（最右边的节点），存入结果
                if (i == n - 1) {
                    res.add(node.val);
                }

                // 正常的 BFS 入队顺序（先左后右）
                if (node.left != null) {
                    queue.add(node.left);
                }
                if (node.right != null) {
                    queue.add(node.right);
                }
            }
        }

        return res;
    }
}
```



### 解法2: DFS

先递归右子树，再递归左子树，当某个深度首次到达时，对应的节点就在右视图中。

```java
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        dfs(root, 0, ans);
        return ans;
    }

    private void dfs(TreeNode root, int depth, List<Integer> ans) {
        if (root == null) {
            return;
        }
        if (depth == ans.size()) { // 这个深度首次遇到
            ans.add(root.val);
        }
        dfs(root.right, depth + 1, ans); // 先递归右子树，保证首次遇到的一定是最右边的节点
        dfs(root.left, depth + 1, ans);
    }
}
```

它的核心机制在于：**利用“先右后左”的递归顺序 + 动态匹配结果集长度 (`ans.size()`)**。



**核心原理拆解**

##### 1. 递归访问顺序：根 --->  右 --->  左

一般的 DFS 深度遍历通常是“先左后右”，但这里故意先递归 `dfs(root.right, ...)`，再递归 `dfs(root.left, ...)`。

- 这样能保证：对于树的每一层，**最右侧的节点绝对是第一个被 DFS 访问到的节点**。

##### 2. 判断条件：`depth == ans.size()`

这是整段代码最精妙的地方：

- `ans` 用于存放最终的右视图结果。初始时 `ans.size()` 为 `0`。
- `depth` 表示当前节点在树中的深度（根节点深度为 `0`）。
- **当第一次来到某一层 `depth` 时**：因为 `ans` 还没有存过这一层的节点，所以 `ans.size()` 恰好等于 `depth`！判断成立，存入节点值。
- **当后续再来到该层（通过左子树遍历过来）时**：由于之前最右侧节点已经让 `ans` 增加了一个元素，此时 `ans.size()` 已经变成了 `depth + 1`，判断不再成立（`depth == ans.size()` 为假），左边的节点就会被自动忽略。



## 104. 二叉树的最大深度



### 解法一: 深度优先搜索

如果我们知道了左子树和右子树的最大深度 *l* 和 *r*，那么该二叉树的最大深度即为

```
max(l,r) + 1
```

```java
class Solution {
    public int maxDepth(TreeNode root) {
        // 1. 递归出口 / 基准条件：遇到空节点，高度为 0
        if (root == null) {
            return 0;
        } else {
            // 2. 递归求出【左子树】的最大深度
            int leftHeight = maxDepth(root.left);
            
            // 3. 递归求出【右子树】的最大深度
            int rightHeight = maxDepth(root.right);
            
            // 4. 当前节点的高度 = 左右子树中较深的那一个 + 1（1代表当前节点自己）
            return Math.max(leftHeight, rightHeight) + 1;
        }
    }
}
```



**核心思想：分治与递归（Bottom-up）**

这道题用到了经典的分治（Divide and Conquer）思想：

1. **要求整棵树的最大深度** --->  等价于要求：`1 + Max(左子树最大深度, 右子树最大深度)`。
2. **基准条件（Base Case）---> 当遍历到空节点 `null` 时，深度为 `0`。

通过自底向上（Bottom-up）的方式，把子问题的答案逐层向上汇总，最终得到全树的高度。



### 解法二: 广度优先搜索

**核心运行逻辑**

1. **按层清空**：
   - 每次外层 `while (!queue.isEmpty())` 循环开始时，`size` 记录了**当前层的所有节点数量**。
   - 内层 `while (size > 0)` 负责把**这一层的节点全部弹出**，同时把**下一层的子节点全放进队列**。
2. **层数累加**：
   - 当内层循环结束，说明**整整一层已经处理完毕**。
   - 此时执行 `ans++`，代表树的深度加 1。
3. **结束返回**：
   - 队列为空时，说明所有层都已经跑完，`ans` 就是最终的最大深度。

> 它的核心思想是：**“按层出队，每处理完一层，深度（层数）`ans` 就加 1”**。

```java
class Solution {
    public int maxDepth(TreeNode root) {
        // 1. 特判：如果是空树，深度直接为 0
        if (root == null) {
            return 0;
        }
        
        // 2. 初始化辅助队列，并将根节点放入
        Queue<TreeNode> queue = new LinkedList<TreeNode>();
        queue.offer(root); // offer() 和 add() 作用基本一致，都是将元素放入队尾
        
        int ans = 0; // 记录树的最大深度（层数）

        // 3. 当队列不为空，说明还有下一层的节点需要处理
        while (!queue.isEmpty()) {
            int size = queue.size(); // 【关键点】：锁死当前层的节点数量
            
            // 4. 内层循环：把【当前层】的 size 个节点全部弹出来
            while (size > 0) {
                TreeNode node = queue.poll(); // 出队一个节点
                
                // 将它的左右子节点（属于下一层）放入队列
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
                
                size--; // 当前层待处理节点数 -1
            }
            
            // 5. 【核心】：内层 while 结束，说明“整整一层”已经全部弹完
            ans++; // 深度 +1
        }

        return ans; // 返回总层数
    }
}
```





## 543. 二叉树的直径

它的核心机制在于：**巧妙借用“求最大深度”的递归过程，在自底向上返回高度的同时，顺便更新最大路径长度。**

**核心概念拆解**

- **什么是二叉树的直径？**
  - 任意两个节点之间路径长度的最大值（路径长度 = 经过的边数）。
- **直径与高度的关系：**
  - 对于树中的**任意一个节点**，穿过该节点的最长路径 = **`左子树最大深度 + 右子树最大深度`**。
  - 整棵树的直径，就是所有节点中 `left + right` 的**最大值**。

```java
class Solution {
    // 1. 全局变量：用于记录遍历过程中遇到的最大直径（边数）
    public int maxlen = 0;

    public int diameterOfBinaryTree(TreeNode root) {
      maxDepth(root); // 1. 这一步执行完后，整棵树都遍历过了，全局变量 maxlen 已经拿到了最大值
    
    	return maxlen;  // 2. 主函数把存好的最终结果 maxlen 提交出去
    }

    // 这个函数做两件事：
    // 1. 计算以 root 为根的子树的最大深度（返回值）
    // 2. 顺便更新全局的最大直径 maxlen
    public int maxDepth(TreeNode root){
        if(root == null){
            return 0; // 空节点深度为 0
        }

        int left = maxDepth(root.left);   // 递归计算左子树深度
        int right = maxDepth(root.right); // 递归计算右子树深度

        // 【核心代码】：更新全局最大直径
        // left + right 代表穿过当前 root 节点的“左深度 + 右深度”
        // 这里的边数正好等于左节点数 + 右节点数，所以直接相加
        maxlen = Math.max(maxlen, left + right);

        // 返回当前节点作为根节点时的子树最大深度（加 1 代表加上当前节点这一层）
        return Math.max(left, right) + 1;
    }
}
```

易错点: 

**`return Math.max(left, right) + 1`（返回值）**：

- 代表的是“从当前节点往下看，单侧最长能伸多深”**（即当前子树的**高度/深度）。
- 这个值是**向上提供给父节点**使用的。

**`maxlen`（全局变量）**：

- 代表的是“穿过当前节点，连接左最深和右最深形成折返的总路径（直径）”。
- 这是我们要的最终答案，但**不能往上传**！

**`maxlen = left + right`** 是当前节点**内部“打通左右”\**算出来的\**倒 V 字形折返路径**（用于更新全局答案）。

- **`Math.max(left, right) + 1`** 是当前节点向上一级父节点**汇报的“单侧直线深度”**（只取左右最长的一条腿，再加上当前节点自己）。

如果直接 `return maxlen`，就会把“折返路径”误当作“单侧深度”传给上层，后续算出来的路径就会在树里“乱画人字形”，得出完全错误的答案。





## 94. 二叉树的中序遍历 (Inorder Traversal)



**中序遍历（Inorder Traversal）** 的顺序是：

> **左子树 --->  根节点 ---> 右子树**。



### 解法一: DFS

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        dfs(root, res);
        return res;
    }

    private void dfs(TreeNode node, List<Integer> res) {
        if (node == null) {
            return;
        }
        dfs(node.left, res);  // 1. 先递归左子树
        res.add(node.val);     // 2. 再处理根节点
        dfs(node.right, res); // 3. 最后递归右子树
    }
}
```



### 解法二: 栈 迭代解法（面试常考

由于递归本质上也是利用系统栈，我们可以显示地使用自定义栈（Stack）来模拟这个过程：

1. 一直向左走，把沿途的所有节点压入栈中（找到最左边的节点）。
2. 当不能再向左时，弹出栈顶节点（此时就是“根”），将其值加入结果集。
3. 转向该节点的右子树，重复上述过程。

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode curr = root;

        while (curr != null || !stack.isEmpty()) {
            // 1. 一直向左走，一路压栈
            while (curr != null) {
                stack.push(curr);
                curr = curr.left;
            }
            // 2. 到了最左边，弹出栈顶节点并记录
            curr = stack.pop();
            res.add(curr.val);
            
            // 3. 转向右子树
            curr = curr.right;
        }

        return res;
    }
}
```



**小结：前序、中序、后序的代码区别**

递归解法中，三种遍历**唯一的区别就是 `res.add(node.val)` 这一行放在哪里**：

- **前序遍历（前）**：`res.add` --->  `dfs(left)` ---> `dfs(right)`
  - （根 ---> 左 ---> 右）
- **中序遍历（中）**：`dfs(left)` ---> `res.add` ---> `dfs(right)`
  - （左 ---> 根 ---> 右）
- **后序遍历（后）**：`dfs(left)` ---> `dfs(right)` ---> `res.add`
  - （左 ---> 右 ---> 根）
