## 102 二叉树的层序遍历

### DFS递归

```java
void dfs(TreeNode root) {
    if (root == null) {
        return;
    }
    dfs(root.left);
    dfs(root.right);
}
```



### BFS基础遍历

```java
void bfs(TreeNode root) {
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.add(root);
    while (!queue.isEmpty()) {
        TreeNode node = queue.poll(); // Java 的 pop 写作 poll()
        if (node.left != null) {
            queue.add(node.left);
        }
        if (node.right != null) {
            queue.add(node.right);
        }
    }
}
```

BFS 遍历使用队列数据结构

BFS 遍历: 一维数组

层序遍历: 二维数组

- 我们 **无法区分队列中的结点来自哪一层**
- 因此，我们需要稍微修改一下代码，在每一层遍历开始前，先记录队列中的结点数量 *n*（也就是这一层的结点数量），然后一口气处理完这一层的 *n* 个结点

```java
// 二叉树的层序遍历
void bfs(TreeNode root) {
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.add(root);
    while (!queue.isEmpty()) {
        int n = queue.size();
        for (int i = 0; i < n; i++) { 
            // 变量 i 无实际意义，只是为了循环 n 次
            TreeNode node = queue.poll();
            if (node.left != null) {
                queue.add(node.left);
            }
            if (node.right != null) {
                queue.add(node.right);
            }
        }
    }
}
```

可以看到，在 while 循环的每一轮中，都是将当前层的所有结点出队列，再将下一层的所有结点入队列，这样就实现了层序遍历。

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>(); // 1. 用于保存最终按层分组的结果
  // List<List<Integer>> - 因为二叉树的层序遍历需要返回的是 “按层分组” 的结果，而不是一个扁平的一维列表。

    Queue<TreeNode> queue = new ArrayDeque<>(); // 2. 创建辅助队列
    if (root != null) {
        queue.add(root);                        // 3. 特判：根节点不为空时入队，开启 BFS
    }

    while (!queue.isEmpty()) {                  // 4. 当队列不为空，说明还有待处理的节点
        int n = queue.size();                   // 5. 关键点：获取【当前层】的节点个数
        List<Integer> level = new ArrayList<>();// 6. 用于存放【当前层】所有节点的值

        for (int i = 0; i < n; i++) {           // 7. 精确循环 n 次，只处理当前层的节点
            TreeNode node = queue.poll();       // 8. 节点出队
            level.add(node.val);                // 9. 将节点值存入当前层列表

            // 10. 将下一层的子节点依次入队（按从左到右的顺序）
            if (node.left != null) {
                queue.add(node.left);
            }
            if (node.right != null) {
                queue.add(node.right);
            }
        }
        res.add(level);                         // 11. 将收集好的当前层结果加入最终列表
    }

    return res;                                 // 12. 返回遍历结果
}
```

核心思想: 

> - **核心数据结构**：使用 **队列（`Queue`）**，遵循 **先进先出（FIFO）** 的原则。
> - **分层处理机制**：在进入每一层的循环时，通过 `int n = queue.size()` **提前记录当前层的节点总数**。这一步是把“按层分组”和“普通 BFS”区分开的关键，保证了内层 `for` 循环只处理属于当前层的节点。



## 199. 二叉树的右视图 

### 解法1: BFS

套用102题BFS的模板, 把每一层的最后一个节点值保存到答案中

- 前置题目: [102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/?envType=study-plan-v2&envId=top-100-liked)



核心解题思路

> 当你从右边看一棵树时，**每一层你只能看到最右边的那个节点**。因此，解答思路非常直接：
>
> 1. **进行标准层序遍历（BFS）**，一层一层地处理节点。
> 2. 在处理每一层时，找到**该层的最后一个节点**（即最右侧节点）。
> 3. 把这个节点的值加入结果集 `List<Integer>`。

### 

```java
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) {
            return res;
        }

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.add(root);

        while (!queue.isEmpty()) {
            int n = queue.size(); // 当前层的节点个数 
          // 快照：此时队列里装的，百分之百“全都是”且“只有”当前层的节点！

            for (int i = 0; i < n; i++) {
                TreeNode node = queue.poll(); 

                // 关键点：如果是当前层的最后一个节点（最右边的节点），存入结果
                if (i == n - 1) {
                    res.add(node.val);
                }

                // 正常的 BFS 入队顺序（先左后右）
                if (node.left != null) {
                    queue.add(node.left);
                }
                if (node.right != null) {
                    queue.add(node.right);
                }
            }
        }

        return res;
    }
}
```



### 解法2: DFS

先递归右子树，再递归左子树，当某个深度首次到达时，对应的节点就在右视图中。

```java
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        dfs(root, 0, ans);
        return ans;
    }

    private void dfs(TreeNode root, int depth, List<Integer> ans) {
        if (root == null) {
            return;
        }
        if (depth == ans.size()) { // 这个深度首次遇到
            ans.add(root.val);
        }
        dfs(root.right, depth + 1, ans); // 先递归右子树，保证首次遇到的一定是最右边的节点
        dfs(root.left, depth + 1, ans);
    }
}
```

它的核心机制在于：**利用“先右后左”的递归顺序 + 动态匹配结果集长度 (`ans.size()`)**。



**核心原理拆解**

##### 1. 递归访问顺序：根 --->  右 --->  左

一般的 DFS 深度遍历通常是“先左后右”，但这里故意先递归 `dfs(root.right, ...)`，再递归 `dfs(root.left, ...)`。

- 这样能保证：对于树的每一层，**最右侧的节点绝对是第一个被 DFS 访问到的节点**。

##### 2. 判断条件：`depth == ans.size()`

这是整段代码最精妙的地方：

- `ans` 用于存放最终的右视图结果。初始时 `ans.size()` 为 `0`。
- `depth` 表示当前节点在树中的深度（根节点深度为 `0`）。
- **当第一次来到某一层 `depth` 时**：因为 `ans` 还没有存过这一层的节点，所以 `ans.size()` 恰好等于 `depth`！判断成立，存入节点值。
- **当后续再来到该层（通过左子树遍历过来）时**：由于之前最右侧节点已经让 `ans` 增加了一个元素，此时 `ans.size()` 已经变成了 `depth + 1`，判断不再成立（`depth == ans.size()` 为假），左边的节点就会被自动忽略。



## 104. 二叉树的最大深度



### 解法一: 深度优先搜索

如果我们知道了左子树和右子树的最大深度 *l* 和 *r*，那么该二叉树的最大深度即为

```
max(l,r) + 1
```

```java
class Solution {
    public int maxDepth(TreeNode root) {
        // 1. 递归出口 / 基准条件：遇到空节点，高度为 0
        if (root == null) {
            return 0;
        } else {
            // 2. 递归求出【左子树】的最大深度
            int leftHeight = maxDepth(root.left);
            
            // 3. 递归求出【右子树】的最大深度
            int rightHeight = maxDepth(root.right);
            
            // 4. 当前节点的高度 = 左右子树中较深的那一个 + 1（1代表当前节点自己）
            return Math.max(leftHeight, rightHeight) + 1;
        }
    }
}
```



**核心思想：分治与递归（Bottom-up）**

这道题用到了经典的分治（Divide and Conquer）思想：

1. **要求整棵树的最大深度** --->  等价于要求：`1 + Max(左子树最大深度, 右子树最大深度)`。
2. **基准条件（Base Case）---> 当遍历到空节点 `null` 时，深度为 `0`。

通过自底向上（Bottom-up）的方式，把子问题的答案逐层向上汇总，最终得到全树的高度。



### 解法二: 广度优先搜索

**核心运行逻辑**

1. **按层清空**：
   - 每次外层 `while (!queue.isEmpty())` 循环开始时，`size` 记录了**当前层的所有节点数量**。
   - 内层 `while (size > 0)` 负责把**这一层的节点全部弹出**，同时把**下一层的子节点全放进队列**。
2. **层数累加**：
   - 当内层循环结束，说明**整整一层已经处理完毕**。
   - 此时执行 `ans++`，代表树的深度加 1。
3. **结束返回**：
   - 队列为空时，说明所有层都已经跑完，`ans` 就是最终的最大深度。

> 它的核心思想是：**“按层出队，每处理完一层，深度（层数）`ans` 就加 1”**。

```java
class Solution {
    public int maxDepth(TreeNode root) {
        // 1. 特判：如果是空树，深度直接为 0
        if (root == null) {
            return 0;
        }
        
        // 2. 初始化辅助队列，并将根节点放入
        Queue<TreeNode> queue = new LinkedList<TreeNode>();
        queue.offer(root); // offer() 和 add() 作用基本一致，都是将元素放入队尾
        
        int ans = 0; // 记录树的最大深度（层数）

        // 3. 当队列不为空，说明还有下一层的节点需要处理
        while (!queue.isEmpty()) {
            int size = queue.size(); // 【关键点】：锁死当前层的节点数量
            
            // 4. 内层循环：把【当前层】的 size 个节点全部弹出来
            while (size > 0) {
                TreeNode node = queue.poll(); // 出队一个节点
                
                // 将它的左右子节点（属于下一层）放入队列
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
                
                size--; // 当前层待处理节点数 -1
            }
            
            // 5. 【核心】：内层 while 结束，说明“整整一层”已经全部弹完
            ans++; // 深度 +1
        }

        return ans; // 返回总层数
    }
}
```





## 543. 二叉树的直径

它的核心机制在于：**巧妙借用“求最大深度”的递归过程，在自底向上返回高度的同时，顺便更新最大路径长度。**

**核心概念拆解**

- **什么是二叉树的直径？**
  - 任意两个节点之间路径长度的最大值（路径长度 = 经过的边数）。
- **直径与高度的关系：**
  - 对于树中的**任意一个节点**，穿过该节点的最长路径 = **`左子树最大深度 + 右子树最大深度`**。
  - 整棵树的直径，就是所有节点中 `left + right` 的**最大值**。

```java
class Solution {
    // 1. 全局变量：用于记录遍历过程中遇到的最大直径（边数）
    public int maxlen = 0;

    public int diameterOfBinaryTree(TreeNode root) {
      maxDepth(root); // 1. 这一步执行完后，整棵树都遍历过了，全局变量 maxlen 已经拿到了最大值
    
    	return maxlen;  // 2. 主函数把存好的最终结果 maxlen 提交出去
    }

    // 这个函数做两件事：
    // 1. 计算以 root 为根的子树的最大深度（返回值）
    // 2. 顺便更新全局的最大直径 maxlen
    public int maxDepth(TreeNode root){
        if(root == null){
            return 0; // 空节点深度为 0
        }

        int left = maxDepth(root.left);   // 递归计算左子树深度
        int right = maxDepth(root.right); // 递归计算右子树深度

        // 【核心代码】：更新全局最大直径
        // left + right 代表穿过当前 root 节点的“左深度 + 右深度”
        // 这里的边数正好等于左节点数 + 右节点数，所以直接相加
        maxlen = Math.max(maxlen, left + right);

        // 返回当前节点作为根节点时的子树最大深度（加 1 代表加上当前节点这一层）
        return Math.max(left, right) + 1;
    }
}
```

易错点: 

**`return Math.max(left, right) + 1`（返回值）**：

- 代表的是“从当前节点往下看，单侧最长能伸多深”**（即当前子树的**高度/深度）。
- 这个值是**向上提供给父节点**使用的。

**`maxlen`（全局变量）**：

- 代表的是“穿过当前节点，连接左最深和右最深形成折返的总路径（直径）”。
- 这是我们要的最终答案，但**不能往上传**！

**`maxlen = left + right`** 是当前节点**内部“打通左右”\**算出来的\**倒 V 字形折返路径**（用于更新全局答案）。

- **`Math.max(left, right) + 1`** 是当前节点向上一级父节点**汇报的“单侧直线深度”**（只取左右最长的一条腿，再加上当前节点自己）。

如果直接 `return maxlen`，就会把“折返路径”误当作“单侧深度”传给上层，后续算出来的路径就会在树里“乱画人字形”，得出完全错误的答案。





## 94. 二叉树的中序遍历 (Inorder Traversal)

前序、中序、后序的代码区别**

递归解法中，三种遍历**唯一的区别就是 `res.add(node.val)` 这一行放在哪里**：

- **前序遍历（前）**：`res.add` --->  `dfs(left)` ---> `dfs(right)`
  - （根 ---> 左 ---> 右）
- **中序遍历（中）**：`dfs(left)` ---> `res.add` ---> `dfs(right)`
  - （左 ---> 根 ---> 右）
- **后序遍历（后）**：`dfs(left)` ---> `dfs(right)` ---> `res.add`
  - （左 ---> 右 ---> 根）



**中序遍历（Inorder Traversal）** 的顺序是：

> **左子树 --->  根节点 ---> 右子树**。



### 解法一: DFS (递归)

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        dfs(root, res);
        return res;
    }

    private void dfs(TreeNode node, List<Integer> res) {
        if (node == null) {
            return;
        }
        dfs(node.left, res);  // 1. 先递归左子树
        res.add(node.val);     // 2. 再处理根节点
        dfs(node.right, res); // 3. 最后递归右子树
    }
}
```

要遍历一棵大树，我们可以把任务拆成三步：

1. **先去把左子树全部遍历完**；
2. **记录当前节点的值**；
3. **再去把右子树全部遍历完**。

对左子树和右子树的处理方式，和主任务完全一样，所以**直接调用自己（递归）**！



### 解法二: 栈 迭代解法（面试常考

由于递归本质上也是利用系统栈，我们可以显示地使用自定义栈（Stack）来模拟这个过程：

1. 一直向左走，把沿途的所有节点压入栈中（找到最左边的节点）。
2. 当不能再向左时，弹出栈顶节点（此时就是“根”），将其值加入结果集。
3. 转向该节点的右子树，重复上述过程。

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
      // 1. 创建我们自己的“背包”（栈），里面用来存 TreeNode
        Deque<TreeNode> stack = new ArrayDeque<>();
      // 游标指针 cur，指向当前正在处理的节点
        TreeNode curr = root;

      // 只要当前节点不为空，或者栈里还有存着的节点，循环就不能停
        while (curr != null || !stack.isEmpty()) {
           // 步骤 1：一路向左，把途径的每一个节点都压入栈中
            while (curr != null) {
                stack.push(curr);
                curr = curr.left; // 继续往左走
            }
          
           // 步骤 2：左边走到头了，从栈顶弹出一个节点（这就是最左边的节点）
            curr = stack.pop();
            res.add(curr.val); // 收集结果（访问根节点）
            
            // 步骤 3：转向右子树
            curr = curr.right;
        }

        return res;
    }
}
```

## 101. 对称二叉树

分解对称二叉树: 

1. `L.val = R.val` ：即此两对称节点值相等。
2. `L.left.val = R.right.val` ：即 *L* 的 左子节点 和 *R* 的 右子节点 对称。
3. `L.right.val = R.left.val` ：即 *L* 的 右子节点 和 *R* 的 左子节点 对称。

### 解法一: 递归（DFS / 最推荐）

写递归的关键是处理好**基准出口（Base Case）**：

```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        if (root == null) {
            return true;
        }
        // 转化为比较：根节点的左子树 和 右子树 是否镜像对称
        return check(root.left, root.right);
    }

    private boolean check(TreeNode p, TreeNode q) {
        // 1. 两个都为空，对称
        if (p == null && q == null) {
            return true;
        }
        // 2. 只有一个为空，或者值不相等，不对称
        if (p == null || q == null || p.val != q.val) {
            return false;
        }
        // 3. 递归比较：p的左 与 q的右 && p的右 与 q的左
        return check(p.left, q.right) && check(p.right, q.left);
    }
}
```

### **解法二：迭代法（BFS / 队列）**

如果不习惯递归，也可以用**队列**模拟 BFS：成对入队，成对出队比较。

```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        if (root == null) return true;

        Queue<TreeNode> queue = new LinkedList<>();
        // 将根节点的左右子树成对压入队列
        queue.offer(root.left);
        queue.offer(root.right);

        while (!queue.isEmpty()) {
            // 每次成对取出两个节点进行比较
            TreeNode p = queue.poll();
            TreeNode q = queue.poll();

            if (p == null && q == null) continue;
            if (p == null || q == null || p.val != q.val) return false;

            // 按照镜像顺序成对入队：
            // 1. p 的左孩子 与 q 的右孩子 成对
            queue.offer(p.left);
            queue.offer(q.right);

            // 2. p 的右孩子 与 q 的左孩子 成对
            queue.offer(p.right);
            queue.offer(q.left);
        }

        return true;
    }
}
```

## 108.  将有序数组转换为二叉搜索树

（Convert Sorted Array to Binary Search Tree）

这是一个经典的二分查找与树形结构结合的题目。由于输入数组已经是**升序排列**的，要构建一棵**高度平衡**的二叉搜索树（BST），我们只需要每次选择数组的**中间元素**作为当前子树的根节点。这样可以保证根节点的左右两侧元素数量尽可能相等，从而达到高度平衡。

💡 核心思路

1. **寻找中点**：每次找到当前数组区间的中间位置 `mid`，将其作为根节点。
2. **递归构建**：
   - `mid` 左边的子数组用来构建左子树。
   - `mid` 右边的子数组用来构建右子树。
3. **递归边界**：当左边界大于右边界（`left > right`）时，说明区间为空，返回 `null`。

### **核心定义回顾**

1. **二叉搜索树（BST）**：对于任意节点，其左子树所有节点的值都小于它，右子树所有节点的值都大于它。
2. **中序遍历的特性**：二叉搜索树的中序遍历（左 $\rightarrow$ 根 $\rightarrow$ 右）结果恰好是一个升序序列。
3. **高度平衡**：每一个节点的左右子树高度差的绝对值不超过 $1$。

### [二叉搜索树](https://www.hello-algo.com/chapter_tree/binary_search_tree/) 

二叉搜索树（binary search tree）满足以下条件。

1. 对于根节点，左子树中所有节点的值 根节点的值 右子树中所有节点的值。
2. 任意节点的左、右子树也是二叉搜索树，即同样满足条件 `1.` 。

### 解法: 递归(二分分治) 

题目给出的数组已经是一个升序数组，这正好对应二叉搜索树的**中序遍历**结果。

要构造出一棵**高度平衡**的树，最简单直接的方法就是：**每次都挑选数组的正中间元素作为根节点**。

- 选择中间元素做根，左边的元素自然形成左子树，右边的元素形成右子树。
- 这样左右两边的元素数量相差最多为 $1$，从而天然地保证了左右子树的高度平衡！

这就是典型的**分治法（Divide and Conquer）/ 双指针递归**。

```java
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        // 传入数组左边界 0 和右边界 nums.length - 1
        return buildTree(nums, 0, nums.length - 1);
    }

    private TreeNode buildTree(int[] nums, int left, int right) {
        // 1. 递归出口 / 基准条件：当左边界大于右边界时，说明区间为空，返回 null
        if (left > right) {
            return null;
        }

        // 2. 选择中间元素作为当前根节点（防溢出写法：left + (right - left) / 2）
        int mid = left + (right - left) / 2;
        TreeNode root = new TreeNode(nums[mid]);

        // 3. 递归构造左子树（区间为 [left, mid - 1]）
        root.left = buildTree(nums, left, mid - 1);

        // 4. 递归构造右子树（区间为 [mid + 1, right]）
        root.right = buildTree(nums, mid + 1, right);

        // 5. 返回构造好的根节点
        return root;
    }
}
```

>  这道题的本质就是“二分法”**：**“每次都挑正中间的元素当根节点，左边的给左子树，右边的给右子树，递归解决”

因为中间位置的数字 `nums[mid]` 已经被我们**拎出来当成了根节点**，所以剩下的数字被天然地分割成了两部分：

- **`[left, mid - 1]`**：`mid` 左边的所有数字（都比 `nums[mid]` 小，用来构造**左子树**）。
- **`[mid + 1, right]`**：`mid` 右边的所有数字（都比 `nums[mid]` 大，用来构造**右子树**）。

left 和 right是索引

>  什么情况会触发 `left > right`？
>
> 当你递归走到**二叉树最底层的叶子节点**时，就会触发这个条件。

## 98. 验证二叉搜索树

这道题是二叉树面试中的**高频必考题**。看起来很简单，但极其容易掉进陷阱！

>  **核心逻辑**：BST 的要求是“左子树的**所有**节点都小于根节点，右子树的**所有**节点都大于根节点”，而不仅仅是直接相邻的节点

容易只比较子树的节点, **需要有全局观**

```java
// ❌ 错误示范！
boolean isValidBST(TreeNode root) {
    if (root == null) return true;
    // 只检查了当前节点和直接左右子节点的关系
    if (root.left != null && root.left.val >= root.val) return false;
    if (root.right != null && root.right.val <= root.val) return false;
    
    return isValidBST(root.left) && isValidBST(root.right);
}
```



### 解法一: 中序遍历（最直观、推荐）

> 对一棵合法的 BST 进行“中序遍历”（左 --->  根 ---> 右），得到的结果必须是一个【严格递增】的序列

所以我们只需要中序遍历，并用一个变量 `prev` 记录**上一次遍历到的节点值**。只要当前节点的值小于或等于 `prev`，就说明破坏了递增性，直接返回 `false` 

```java
class Solution {
    // 记录中序遍历时上一个节点的值（用 Long 避开 Integer.MIN_VALUE 的边界坑）
    private long prev = Long.MIN_VALUE;

    public boolean isValidBST(TreeNode root) {
        if (root == null) return true;

        // 1. 先递归检查左子树
        if (!isValidBST(root.left)) {
            return false;
        }

        // 2. 检查当前节点：必须严格大于上一个节点值
        if (root.val <= prev) {
            return false; // 不满足严格递增，直接宣告失败
        }
        prev = root.val; // 更新 prev 为当前节点值

        // 3. 再递归检查右子树
        return isValidBST(root.right);
    }
}
```

#### 易错点

> `private long pre = Long.MIN_VALUE`; 这个为什么要写在isValidBST 外面? 

解法本质是**中序遍历**，用 `pre` 记录上一个访问的节点值。关键点在于：

1. **`isValidBST` 会被递归调用多次**（每个节点调用一次）。
2. 如果 `pre` 写在方法**内部**，每次递归调用都会**重新初始化**为 `Long.MIN_VALUE`，这样就无法记住"上一个节点的值"，比较就失去了意义。
3. 写在**外部**作为成员变量，`pre` 在整个递归过程中**只有一份**，所有递归调用共享同一个 `pre`，才能正确追踪中序遍历的顺序。



#### 引入`Long` ? 

`Long.MIN_VALUE`（$-2^{63}$）是一个**远小于 `Integer.MIN_VALUE`** 的超级最小值

因为 `node.val` 是 `int` 类型，它的最小值顶多也就是 `Integer.MIN_VALUE`，**绝对不可能到达 `Long.MIN_VALUE`**。



### 解法二 (TreeNode prev)

另一种不引入 `Long` 的写法（用对象指针 `TreeNode`）

如果不想借助 `Long` 类型，力扣中非常经典的另一种规避极值问题的技巧是：**用 `TreeNode prev` 指针记录上一个节点**，而不是直接存数值

```java
class Solution {
    // 用对象记录上一个节点，初始为 null，就不存在任何极值撞衫的问题了
    private TreeNode prev = null;

    public boolean isValidBST(TreeNode root) {
        if (root == null) return true;

        if (!isValidBST(root.left)) return false;

        // 只有当 prev 不为空时（说明不是第一个节点），才去比较值
        if (prev != null && root.val <= prev.val) {
            return false;
        }
        prev = root; // 指针指向当前节点

        return isValidBST(root.right);
    }
}
```



### **解法 3：上下界限定法（区间限制）**

既然根节点会限制子树节点的取值范围，我们可以给每个节点传入一个“合法数值区间 `(min, max)`”：

- 根节点可以为任意值，区间为 `(-∞, +∞)`。
- 向**左子树**走时：左子树的所有节点必须**小于**当前节点，所以更新**上限 `max = root.val`**。
- 向**右子树**走时：右子树的所有节点必须**大于**当前节点，所以更新**下限 `min = root.val`**。

```java
class Solution {
    public boolean isValidBST(TreeNode root) {
        // 初始区间为 (Long.MIN_VALUE, Long.MAX_VALUE)，防止节点值为 Integer 极值
        return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    private boolean validate(TreeNode node, long min, long max) {
        if (node == null) return true;

        // 当前节点值不在合法区间 (min, max) 内，返回 false
        if (node.val <= min || node.val >= max) {
            return false;
        }

        // 递归检查左子树（上限变成当前节点值）和右子树（下限变成当前节点值）
        return validate(node.left, min, node.val) && validate(node.right, node.val, max);
    }
}
```

二叉树的中序遍历即按照访问**左子树——根节点——右子树**的方式遍历二叉树；在访问其左子树和右子树时，我们也按照同样的方式遍历；直到遍历完整棵树。

难点: 

1. 为什么是--k 不是k--
2. 为什么用Deque

在这段代码的上下文中，**`--k` 和 `k--` 的执行效果没有任何区别**。

因为这一行是作为**独立语句**执行的：

```java
root = stack.pop();
--k; // 独立语句，执行完后 k 的值都会减 1
if (k == 0) {
    break;
}
```

- **前缀自减 (`--k`)**：先将 k 自减 1，然后返回自减后的值。
- **后缀自减 (`k--`)**：先返回 k 的当前值，然后再将 k 自减 1。



2. 为什么用 `Deque`？

在 Java 中，这里使用 `Deque`（双端队列）主要是因为 **Java 官方推荐用它来替代古老的 `Stack` 类**。

- **历史遗留问题 (`java.util.Stack`)**： Java 早期提供的 `Stack` 类继承自 `Vector`。为了保证线程安全，`Stack` 的所有方法都加了 synchronized 锁，这带来了不必要的性能开销。此外，继承自 `Vector` 意味着它暴露出了一些不属于“栈”的数据结构操作（如随意按索引插入/删除元素），违反了面向对象设计原则。
- **现代替代方案 (`java.util.Deque`)**： `Deque`（Double Ended Queue）是一个接口。使用 `ArrayDeque` 实现了该接口后，可以高效地作为单线程下的栈（LIFO，后进先出）来使用：
  - **`push(e)`**：压入栈顶
  - **`pop()`**：弹出栈顶
  - **`peek()`**：查看栈顶

`ArrayDeque` 基于动态数组实现，没有线程同步锁的开销，在用作栈时**性能显著优于 `java.util.Stack`**。

### 解法二: DFS (递归)

```java
class Solution {
    private int count;
    private int result;

    public int kthSmallest(TreeNode root, int k) {
        this.count = k;
        dfs(root);
        return result;
    }

    private void dfs(TreeNode node) {
        // 递归基：节点为空，或者已经找到了答案（剪枝）
        if (node == null || count == 0) {
            return;
        }

        // 1. 递归遍历左子树
        dfs(node.left);

        // 2. 处理当前节点
        count--;
        if (count == 0) {
            result = node.val;
            return; // 找到第 k 小的元素，触发剪枝
        }

        // 3. 递归遍历右子树
        dfs(node.right);
    }
}
```

DFS（递归）解法的核心逻辑依然是**中序遍历**：先递归遍历左子树，再处理当前节点，最后递归遍历右子树。

由于递归函数会不断深入，我们需要通过**全局/成员变量**来跨递归层级记录当前访问的节点计数 k 以及最终的答案。

#### 关键细节说明

1. **剪枝优化 (`count == 0`)**：
   - 一旦 `count` 减到 `0`，说明已经找到了目标值并存入 `result`。
   - 此时在递归开头增加 `if (count == 0) return;` 检查，可以立即终止后续无用的递归分支（停止遍历右子树及上层节点），提升执行效率。
2. **成员变量传递状态**：
   - Java 中基本数据类型（如 `int`）是值传递，如果在递归参数中传 `int k`，各层递归之间无法同步修改后的 k 值。
   - 因此采用成员变量 `count`（或者用长度为 1 的数组 `int[] count` 模拟引用传递）来跨层同步计数。

为什么“在递归参数中传 `int k` 无法同步”？

- Java 在调用方法传参时，**一律是值传递（Pass by Value）**。

- 当你把一个基本类型（如 `int k`）传给函数时，Java 会**复制一份副本**给这个函数。如果在函数内部修改了 `k` 的值，修改的只是当前这个局部副本，**上层调用者的 `k` 完全不受影响**。

解决方案：使用类成员变量（全局同步）

- 成员变量存储在对象的堆内存中，所有递归层级共享同一个 `this.count` 变量。任何一层执行 `count--`，全局的 `count` 都会真实减少。





## 105. [从前序与中序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/description/?envType=study-plan-v2&envId=top-100-liked) 

![image-20260909170558553](/Users/ruixue/Library/Application Support/typora-user-images/image-20260909170558553.png)

### 解题核心思路

构建二叉树的关键在于利用两种遍历方式的特性：

- **前序遍历（Preorder）**：`[根节点, [左子树前序], [右子树前序]]` --->  数组的第一个元素**必定是根节点**。
- **中序遍历（Inorder）**：`[[左子树中序], 根节点, [右子树中序]]` ---> 只要找到根节点在中序数组中的位置，就可以划分出**左子树和右子树的节点数量**。

**算法步骤：**

1. 从前序遍历找到根节点的值。
2. 用哈希表（HashMap）快速快速在中序遍历中定位根节点的索引。
3. 计算左子树的节点数量。
4. 递归构建左子树和右子树，并挂载到当前根节点上。



### 解法一: 递归

![image-20260909171741811](/Users/ruixue/Library/Application Support/typora-user-images/image-20260909171741811.png)

为了避免频繁切割数组，我们使用索引范围（闭区间）来指示子树在数组中的位置：

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    // 缓存中序遍历中 <节点值, 数组索引> 的映射，实现 O(1) 查找
    private Map<Integer, Integer> inorderIndexMap;

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        inorderIndexMap = new HashMap<>();
        for (int i = 0; i < inorder.length; i++) {
            inorderIndexMap.put(inorder[i], i);
        }
        
        return build(preorder, 0, preorder.length - 1,
                     inorder, 0, inorder.length - 1);
    }

    /**
     * @param preStart 当前子树在前序数组中的起始索引
     * @param preEnd   当前子树在前序数组中的结束索引
     * @param inStart  当前子树在中序数组中的起始索引
     * @param inEnd    当前子树在中序数组中的结束索引
     */
    private TreeNode build(int[] preorder, int preStart, int preEnd,
                           int[] inorder, int inStart, int inEnd) {
        // 递归基：区间不合法，说明子树为空
        if (preStart > preEnd || inStart > inEnd) {
            return null;
        }

        // 1. 前序遍历的第一个元素就是根节点的值
        int rootVal = preorder[preStart];
        TreeNode root = new TreeNode(rootVal);

        // 2. 在中序遍历中获取根节点的索引
        int rootInorderIndex = inorderIndexMap.get(rootVal);

        // 3. 计算左子树的节点数量
        int leftTreeSize = rootInorderIndex - inStart;

        // 4. 递归构造左子树
        // 左子树前序范围：[preStart + 1, preStart + leftTreeSize]
        // 左子树中序范围：[inStart, rootInorderIndex - 1]
        root.left = build(preorder, preStart + 1, preStart + leftTreeSize,inorder, inStart, rootInorderIndex - 1);

        // 5. 递归构造右子树
        // 右子树前序范围：[preStart + leftTreeSize + 1, preEnd]
        // 右子树中序范围：[rootInorderIndex + 1, inEnd]
        root.right = build(preorder, preStart + leftTreeSize + 1, preEnd, inorder, rootInorderIndex + 1, inEnd);

        return root;
    }
}
```

| **`preEnd`**   | `preorder.length - 1` | 当前子树在 `preorder` 中的**结束索引**（整棵树的终点是最后一个元素） |
| **`inorder`**  | `inorder`             | 中序遍历的完整数组                                           |

#### 哈希表映射

关键在这一行：

```python
index = {element: i for i, element in enumerate(inorder)}
```





应用代码

它把中序遍历构建成一个**值 → 索引**的字典，例如 `inorder = [9, 3, 15, 20, 7]` 会变成：

```python
{9: 0, 3: 1, 15: 2, 20: 3, 7: 4}
```

**为什么需要它？** 因为每次递归时，你需要快速知道"根节点在中序遍历中的哪个位置"，才能划分左右子树。

- 如果不用哈希表：每次都要**线性扫描**中序数组找根，时间复杂度为 O(n²)
- 用了哈希表：**O(1)** 直接查到位置，总时间复杂度降为 **O(n)**

简单来说，哈希映射就是一个**空间换时间**的优化技巧。



### 解法二: 迭代

力扣 105 题（从前序与中序遍历构造二叉树）的**迭代解法**非常巧，它借助显式栈（Stack）模拟了“沿着左分支一路向下建树，碰到叶子节点后回溯接右子树”的过程。

与递归相比，迭代解法**不需要哈希表**，也不需要计算区间长度，空间效率更高。

### 核心思路

沿着前序遍历的顺序，不断往左走（入栈），直到某个节点与中序遍历当前指向的值**相同**，说明这个节点**没有左子树了**，该往右走了。

以 `preorder = [3,9,20,15,7]`, `inorder = [9,3,15,20,7]` 为例：

1. **依次创建前序节点，压入栈中**
   - 创建 `3`，入栈 → `stack = [3]`
2. **判断栈顶是否等于中序当前值**
   - 中序当前指向 `9`，栈顶是 `3`，不等 → 说明 `3` 还有左子树
   - 创建 `9`，作为 `3` 的左孩子，入栈 → `stack = [3, 9]`
3. **栈顶等于中序当前值，开始弹出**
   - 中序当前指向 `9`，栈顶也是 `9`，匹配！
   - 弹出 `9`，中序指针右移 → 指向 `3`
   - 栈顶 `3` 也匹配，弹出 `3`，中序指针右移 → 指向 `15`
4. **最后一个弹出的节点，接上右孩子**
   - 创建 `20`，作为最后弹出的 `3` 的**右孩子**，入栈 → `stack = [20]`
5. 重复以上过程，直到遍历完前序数组

### java 解法

```java
class Solution {
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        if (preorder == null || preorder.length == 0) {
            return null;
        }
        TreeNode root = new TreeNode(preorder[0]);
        Deque<TreeNode> stack = new LinkedList<TreeNode>();
        stack.push(root);
        int inorderIndex = 0;
        for (int i = 1; i < preorder.length; i++) {
            int preorderVal = preorder[i];
            TreeNode node = stack.peek();
            if (node.val != inorder[inorderIndex]) {
                node.left = new TreeNode(preorderVal);
                stack.push(node.left);
            } else {
                while (!stack.isEmpty() && stack.peek().val == inorder[inorderIndex]) {
                    node = stack.pop();
                    inorderIndex++;
                }
                node.right = new TreeNode(preorderVal);
                stack.push(node.right);
            }
        }
        return root;
    }
}
```

```python 
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        if not preorder:
            return None

        root = TreeNode(preorder[0])
        stack = [root] #根节点入栈
        inorderIndex = 0; # 指针

        for i in range (1, len(preorder)):
            preorderVal = preorder[i]
            node = stack[-1]
            
            if node.val != inorder[inorderIndex]: 
                node.left = TreeNode(preorderVal)
                stack.append(node.left)
            else:
                while stack and stack[-1].val == inorder[inorderIndex]:
                    node = stack.pop()
                    inorderIndex += 1
                node.right = TreeNode(preorderVal)
                stack.append(node.right)

        return root
```


这是一个**边界条件检查**，处理输入为空的情况。

- 如果 `preorder` 为空列表 `[]`，说明**没有节点可构建**，直接返回 `None`（空树）。
- 如果传入 `[]` 却不加这个判断，后续代码访问 `preorder[0]` 时会报 **索引越界错误**（`IndexError`）。



```python
for i in range (1, len(preorder)):
            preorderVal = preorder[i]
            node = stack[-1]
```

这几行是迭代法的**主循环入口**，逐行解释：

1. **`for i in range(1, len(preorder))`**
   - 从索引 `1` 开始遍历前序数组，因为索引 `0` 的根节点已经在循环之前创建并入栈了
2. **`preorderVal = preorder[i]`**
   - 取出当前前序遍历的值，准备用它创建新节点
3. **`node = stack[-1]`**
   - 查看**栈顶节点**（`stack[-1]` 是 Python 中取列表最后一个元素的写法）
   - 这个栈顶节点就是新节点的**潜在父节点**——接下来要判断新节点应该挂在它的左边还是右边

简单说：每轮循环拿一个前序值，再看一眼栈顶是谁，然后决定这个新节点该放哪。



```python 
inorder[inorderIndex]

TreeNode(preorderVal)
```

这是 Python 的语法区别：

- **`inorder[inorderIndex]`** — 方括号 `[]` 是**索引访问**，从列表中按位置取值，比如 `inorder[0]` 取第一个元素
- **`inorder(inorderIndex)`** — 圆括号 `()` 是**函数调用**，意味着把 `inorder` 当作一个函数来执行

`TreeNode` 是一个**类（class）**，用圆括号 `()` 是在**调用它的构造函数**，创建一个新节点对象。

| 写法            | 含义                                                      |
| --------------- | --------------------------------------------------------- |
| `inorder[i]`    | `inorder` 是**列表**，用 `[]` 按索引**取值**              |
| `TreeNode(val)` | `TreeNode` 是**类**，用 `()` **调用**构造函数，创建新节点 |

所以：

- `TreeNode(preorderVal)` → 创建了一个值为 `preorderVal` 的新树节点
- 等价于"调用 `TreeNode` 的 `__init__` 方法，传入 `preorderVal` 作为 `val` 参数"

简单记：**列表取值用方括号，创建对象/调用函数用圆括号。**



```python 
if node.val != inorder[inorderIndex]: 
                node.left = TreeNode(preorderVal)
                stack.append(node.left)
```

这是判断新节点应该放在**左边**还是**右边**的核心逻辑：

`if node.val != inorder[inorderIndex]`

- `node.val`：当前栈顶节点的值
- `inorder[inorderIndex]`：中序遍历当前指向的值

> **如果不相等**，说明栈顶节点**还没在中序遍历中被访问到**，意味着它还有左子树没处理完。

所以：

- `node.left = TreeNode(preorderVal)` → 新节点作为栈顶的**左孩子**
- `stack.append(node.left)` → 新节点入栈，继续往左深入

反过来，如果相等呢？

说明栈顶节点在中序遍历中已经到了，**左子树已经建完**，该往右走了——这时就会进入 `else` 分支，不断弹出栈顶，找到最后一个弹出的节点，把新节点挂到它的**右孩子**上。

简单记：**不等就往左走，相等就往右拐。**



```python 
else:
    while stack and stack[-1].val == inorder[inorderIndex]:
        node = stack.pop()
        inorderIndex += 1
    node.right = TreeNode(preorderVal)    # 移到 while 外面
    stack.append(node.right)              # 移到 while 外面
```

这是 `else` 分支，处理"栈顶等于中序当前值"的情况。逐行解释：

- **`while stack and stack[-1].val == inorder[inorderIndex]`**：只要栈顶值等于中序当前值，就不断弹出
- **`node = stack.pop()`**：弹出栈顶，`node` 会被反复更新，循环结束后保留的是**最后一个弹出的节点**
- **`inorderIndex += 1`**：中序指针右移
