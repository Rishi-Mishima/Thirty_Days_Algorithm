这是 LeetCode 76 题 **“最小覆盖子串”** 的官方解法，采用的是 **滑动窗口（双指针）** 算法。

它的目标是：在字符串 `s` 中找到一个最短的连续子串，使其包含字符串 `t` 中的所有字符（包括字符数量）。

### 1. 核心思想：滑窗“拉伸”与“收缩”

你可以把滑动窗口想象成一个用左右指针 `l` 和 `r` 围起来的**弹簧窗口**：

1. **向右拉伸（移动右指针 `r`）：** 扩大窗口，不断把 `s[r]` 包含进来，直到窗口里的字符**凑齐了字符串 `t` 所需的所有字符**。
2. **向左收缩（移动左指针 `l`）：** 一旦凑齐，尝试缩小窗口（让 `l` 右移），剔除左边多余的字符，**寻找最短的合法窗口**。
3. **循环往复：** 当缩小到不合法时，继续右移 `r`，重复上述过程，直到 `r` 到达字符串末尾。



### 2. 关键变量拆解

- **`ori`（哈希表）：** 记录字符串 `t` 中每个字符**需要的数量**（固定不变）。
- **`cnt`（哈希表）：** 记录当前滑动窗口中每个字符**实际拥有的数量**（动态变化）。
- **`check()` 函数：** 遍历 `ori`，检查当前窗口 `cnt` 里的字符数量是不是**每一个都不小于** `ori` 里的要求（即判断“当前窗口是否包含了 `t` 的全部字符”）。
- **`ansL, ansR`：** 记录找到的**最短合法窗口的左闭右开区间 `[ansL, ansR)`**。

### JAVA

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public String minWindow(String s, String t) {
        // 1. 初始化哈希表：记录t的字符频次（need）和窗口字符频次（window）
        Map<Character, Integer> need = new HashMap<>();
        Map<Character, Integer> window = new HashMap<>();

        // 2. 统计t中每个字符的需要频次
        for (char c : t.toCharArray()) {
            need.put(c, need.getOrDefault(c, 0) + 1); // 修正：中文分号→英文分号
        }

        // 3. 滑动窗口核心变量
        int left = 0, right = 0;    // 窗口左右指针
        int valid = 0;              // 窗口中满足need频次的字符数
        int start = 0, len = Integer.MAX_VALUE; // 记录最小窗口的起始索引和长度

        // 4. 扩张窗口（右指针遍历s）
        while (right < s.length()) {
            char c = s.charAt(right);
            right++; // 右指针右移，纳入当前字符

            // 5. 更新窗口内数据（仅处理t需要的字符）
            if (need.containsKey(c)) {
                // 修正：getOrDefualt→getOrDefault（拼写错误）
                window.put(c, window.getOrDefault(c, 0) + 1);
                // 字符c的频次刚好达标，valid+1
                if (window.get(c).equals(need.get(c))) {
                    valid++;
                }
            }

            // 6. 收缩窗口（当窗口包含t的所有字符时，尽可能缩小窗口）
            while (valid == need.size()) { // 修正：收缩条件改为「窗口有效」
                // 7. 更新最小窗口：记录更小的有效窗口
                if (right - left < len) {
                    start = left;          // 保存最小窗口起始索引
                    len = right - left;    // 保存最小窗口长度
                }

                // 8. 左指针移出字符d，收缩窗口
                char d = s.charAt(left);
                

                // 9. 更新窗口内数据（仅处理t需要的字符，避免空指针）
                if (need.containsKey(d)) { // 过滤非目标字符
                    // 先判断：移出前d的频次是否刚好达标，达标则valid-1
                    if (window.get(d).equals(need.get(d))) {
                        valid--;
                    }
                    // 再更新窗口中d的频次（顺序不能反）
                    window.put(d, window.get(d) - 1);
                }
                left++;
            }
        }

        // 10. 返回结果：找到则返回最小子串，否则返回空字符串
        return len == Integer.MAX_VALUE ? "" : s.substring(start, start + len);
    }
}
```



### go

```go
func minWindow(s string, t string) string {
    ori, cnt := map[byte]int{}, map[byte]int{}
    
    // 1. 统计字符串 t 中每个字符出现的次数（目标频次）
    for i := 0; i < len(t); i++ {
        ori[t[i]]++
    }

    sLen := len(s)
    len := math.MaxInt32 // 记录最小窗口的长度，初始设为极大值
    ansL, ansR := -1, -1 // 记录最终最短子串的左右边界索引

    // 辅助函数：判断当前窗口 cnt 是否覆盖了 ori 的所有字符需求
    check := func() bool {
        for k, v := range ori {
            if cnt[k] < v { // 只要有一个字符的数量不够，就返回 false
                return false
            }
        }
        return true
    }

    // 2. 开始滑动窗口：l 是左指针，r 是右指针
    for l, r := 0, 0; r < sLen; r++ {
        // 如果当前右指针指向的字符是 t 里面需要的，就在窗口内统计加 1
        if r < sLen && ori[s[r]] > 0 {
            cnt[s[r]]++
        }

        // 3. 当窗口已经完全包含 t 时，进入循环：尝试缩小左边界 l
        for check() && l <= r {
            // 如果发现当前窗口比之前记录的最小长度还要小，更新答案
            if (r - l + 1 < len) {
                len = r - l + 1
                ansL, ansR = l, l + len // 注意：Go 切片是左闭右开 s[ansL:ansR]
            }

            // 准备把左指针 l 移出窗口，如果 l 指向的字符是 t 里的字符，窗口计数减 1
            if _, ok := ori[s[l]]; ok {
                cnt[s[l]] -= 1
            }
            l++ // 左指针右移，尝试收缩窗口
        }
    }

    // 如果 ansL 还是 -1，说明没有找到任何满足条件的子串
    if ansL == -1 {
        return ""
    }
    // 返回切割好的最短子串
    return s[ansL:ansR]
}
```

### 一、 两个核心哈希表（Map）的定义

代码最开头定义了两个 `map[byte]int`：

```go
ori, cnt := map[byte]int{}, map[byte]int{}
```

1. **`ori`（原目标/清单）：** 记录字符串 `t` 里每个字符**需要多少个**。比如 `t = "ABC"`，那 `ori` 就是 `{'A': 1, 'B': 1, 'C': 1}`。这个表初始化后就**固定不变**了。
2. **`cnt`（当前窗口/网）：** 记录当前滑动窗口（即指针 `l` 到 `r` 之间）里**实际抓到了多少个**字符。这个表会随着指针移动**动态更新**。

### 二、 拆解每一个步骤

#### 第一步：建立目标清单（统计 `t` 的字符频次）

```go
ifor i := 0; i < len(t); i++ {
    ori[t[i]]++
}
```

- **作用：** 遍历字符串 `t`，把每个字符出现的次数存进 `ori` 中。
- **例如：** 如果 `t = "AABC"`，处理完后 `ori` 就是 `{'A': 2, 'B': 1, 'C': 1}`。

#### 第二步：初始化变量与辅助判断函数

```go
sLen := len(s)
len := math.MaxInt32 // 记录历史找到的最短窗口长度，先设为一个极大值
ansL, ansR := -1, -1 // 记录最终找到的最短子串的左、右索引边界
```

紧接着是一个闭包函数 `check()`：

```go
check := func() bool {
    for k, v := range ori {
        if cnt[k] < v {
            return false
        }
    }
    return true
}
```

- **作用：** 检查**当前窗口（`cnt`）\**是否已经\**完全包含了 `t`（`ori`）需要的全部字符**。
- **逻辑：** 遍历 `ori` 中的每一个目标字符 `k` 及其所需数量 `v`：
  - 只要发现窗口里该字符的数量 `cnt[k]` **小于** 所需数量 `v`，说明还没凑齐，立刻返回 `false`。
  - 如果全部字符都满足 `cnt[k] >= v`，说明凑齐了，返回 `true`

### 

#### 第三步：滑动窗口的主循环（核心逻辑）

```go
for l, r := 0, 0; r < sLen; r++ {
```

- **`l`（Left）：** 窗口的左边界指针，初始在 `0`。
- **`r`（Right）：** 窗口的右边界指针，从 `0` 开始不断向右移动（`r++`），拉大窗口。

##### 3.1 进网操作（探索新字符）

```go
if r < sLen && ori[s[r]] > 0 {
    cnt[s[r]]++
}
```

- **逻辑：** 看一眼右指针当前指着的字符 `s[r]`：
  - 如果它是 `t` 里面**需要的字符**（即 `ori[s[r]] > 0`），就把当前窗口统计表 `cnt` 里该字符的数量加 1。
  - 如果它不是需要的字符（比如杂质 `'X'`, `'Y'`），就直接忽略。

##### 3.2 收缩操作（寻找极限最短）

当右指针 `r` 包含够了足够多的字符使得 `check()` 返回 `true` 时，就会进入这个内层的 `for` 循环：

```go
for check() && l <= r {
    // A. 尝试更新最优解
    if (r - l + 1 < len) {
        len = r - l + 1
        ansL, ansR = l, l + len
    }
    
    // B. 把左指针 l 指向的字符移出窗口
    if _, ok := ori[s[l]]; ok {
        cnt[s[l]] -= 1
    }
    
    // C. 左指针右移，收缩窗口
    l++
}
```

这三步的详细执行逻辑：

1. **更新最短记录（A）：** 此时 `r - l + 1` 是当前合法窗口的长度。如果它比之前记录的 `len` 更小，就更新 `len`，并记录下此时的起始索引 `ansL` 和结束索引 `ansR`。
2. **扣减计数（B）：** 准备把左边的 `s[l]` 踢出窗口。如果 `s[l]` 是目标字符（存在于 `ori` 中），必须在 `cnt` 中将它的计数减 1。
3. **缩小窗口（C）：** `l++`，让左边界向右推进一位。
4. **循环检查：** 踢掉 `s[l]` 后，回到 `for` 开头重新调用 `check()`：
   - 如果踢掉后**依然覆盖 `t`**，继续循环，重复上述步骤，进一步缩小窗口。
   - 如果踢掉后**导致不满足要求了**，跳出内层 `for` 循环，外层的 `r++` 继续向右拉大窗口去寻找下一个字符。



当代码运行到这里时，说明右指针 `r` 已经往右拉得足够长，**窗口里的字符已经成功凑齐了 `t` 所需的全部字符**（即 `check()` 返回了 `true`）。

既然已经凑齐了，接下来的任务就是：**在保证“不缺字符”的前提下，把左指针 `l` 尽量往右推，把左边无用的杂质字符踢出去，看看窗口最短能缩小到什么程度。**

###### 1. 循环条件：`check() && l <= r`

- **`check()`**：检查当前窗口里的字符是否依然完整覆盖 `t`。
- **`l <= r`**：确保左指针不会跑跑到右指针后面去。
- **合起来的意思：** 只要当前的窗口**依然合格（没缺字符）**，这个循环就会一直重复执行，疯狂地向右缩窄窗口！一旦踢掉某个字符导致缺人了（`check()` 变 `false`），循环立刻终止。

###### 2. 动作 A：更新历史最短记录

```go
if (r - l + 1 < len) {
    len = r - l + 1
    ansL, ansR = l, l + len
}
```

**`r - l + 1`**：当前窗口的实际字符长度。

> *例子：如果 `l = 2`, `r = 5`，窗口包含索引 `2, 3, 4, 5` 的字符，长度就是 $5 - 2 + 1 = 4$。*

**判断逻辑**：如果发现**当前的窗口长度**比之前记录的**历史最短长度 `len`** 还要短，说明找到了更好的答案！

**更新答案**：

- 把 `len` 更新为这个更小的长度。
- 记录下此时的最佳起始索引 `ansL = l`，以及截取终点 `ansR = l + len`。



###### 3. 动作 B：准备把左边界 `s[l]` 踢出窗口

```go
if _, ok := ori[s[l]]; ok {
    cnt[s[l]] -= 1
}
```

左指针 `l` 马上要向右移动一位了，这意味着 **`s[l]` 这个字符要被扔出窗口**了。

- **`if _, ok := ori[s[l]]; ok`**：先看一眼这个要被踢掉的字符 `s[l]` 是不是 `t` 里面**要求的字符**（即在 `ori` 清单里存不存在）。
- **`cnt[s[l]] -= 1`**：
  - 如果它是目标字符（比如 `'A'`），那踢掉它之后，我们当前窗口统计表 `cnt` 里 `'A'` 的数量就必须减少 1 个。
  - 如果它只是无关的杂质字符（比如 `'X'`），那根本不在 `ori` 里，对我们凑齐目标毫无影响，什么都不用做。

###### 4. 动作 C：左指针真正向右移动

```go
l++
```

将左指针 `l` 向右推进 1 位，真正完成了“缩小窗口”的动作。

**接着回到循环开头：** 重新调用 `check()`。

- 如果扣减后 `cnt` 里的字符数量**依然足够**（比如刚才网里有 2 个 `'A'`，踢掉 1 个还剩 1 个），`check()` 依然是 `true`，循环继续，尝试再踢掉下一个字符！
- 如果扣减后**不够了**（比如原本只有 1 个 `'A'`，踢掉后变 0 个），`check()` 变成了 `false`，内层循环立刻结束，把控制权交还给外层循环（让 `r++` 继续去右边找新的 `'A'`）。



#### 第四步：返回最终答案

```go
if ansL == -1 {
    return "" // 说明全程都没有找到任何一个符合条件的子串
}
return s[ansL:ansR] // 截取并返回找到的最短子串
```

- **注意：** 在 Go 中，切片语法 `s[ansL:ansR]` 是**左闭右开**的（包含 `ansL`，不包含 `ansR`）。
- 因为在第三步中设置的是 `ansR = l + len`，也就是 `ansL + len`，所以截取出来的长度刚好就是 `len`。



### 三、 总结：一次完整的数据追踪

假设 `s = "ADOBECODEBANC"`, `t = "ABC"`

```
1. r 一直向右走，当 r=5 ('C') 时，窗口为 "ADOBEC"
   └── check() 发现凑齐了 'A','B','C'！
   └── 记录当前最优解：ansL=0, ansR=6 (字符串 "ADOBEC"，长度 6)
   └── 开始缩左边：剔除 s[0]('A') 导致不满足 check()，l 变为 1，退出收缩循环。

2. r 继续向右走，到 r=10 ('A') 时，窗口为 "DOBECODEBA"
   └── check() 又凑齐了！
   └── 开始缩左边：依次剔除 'D', 'O'，窗口变成 "BECODEBA" (长度 8，没之前的 6 好，不更新)
   └── 继续剔除 'B' 导致不满足，l 停下。

3. r 继续走到末尾 r=12 ('C')，窗口收缩到 "BANC" (l=9)
   └── check() 凑齐了！
   └── 当前长度 12 - 9 + 1 = 4，比之前的 6 更小！
   └── 更新最优解：ansL=9, ansR=13 (字符串 "BANC"，长度 4)

4. 遍历结束，返回 s[9:13]，即 "BANC"。
```
