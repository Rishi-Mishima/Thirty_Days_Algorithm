# LC53. [最大子数组和](https://leetcode.cn/problems/maximum-subarray/description/?envType=study-plan-v2&envId=top-100-liked)



## 解法一: 动态规划

LeetCode 第 53 题 **“最大子数组和”（Maximum Subarray）** 是算法面试中最高频、最经典的题目之一。

### 一、 题目大意

给你一个整数数组 `nums`，请你找出一个具有**最大和的连续子数组**（子数组最少包含一个元素），并返回其最大和。

**示例：**

> **输入：** `nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]` **输出：** `6` **解释：** 连续子数组 `[4, -1, 2, 1]` 的和最大，为 `6`。

### 二、 最核心的解法：动态规划（或称“贪心思想 / 动态转移”）

这道题最绝妙的地方在于：**我们可以边走边做选择**。

当你遍历到第 `i` 个数字 `x` 时，你有两种选择：

1. **加入前面的队伍：** 把当前数字 `x` 加到前面的连续子数组里（前面的和 + `x`）。
2. **重新单干：** 抛弃前面的子数组，把当前数字 `x` 作为新子数组的**开头**。

#### 什么时候选择“重新单干”？

如果前面的子数组算出来的总和已经是一个**负数**了（比如 `-2`），那它只会拖累后面的数字！任何数加上负数都会变小，所以**只要前面的累加和小于 0，我们就果断抛弃它，从当前数字重新开始计算**。

### 三、 算法推导与代码实现

我们需要两个变量：

- **`pre`（或 `currentSum`）：** 以当前数字结尾的子数组的最大和。
- **`maxSum`：** 记录全局找到过的最大子数组和。

#### 写法一: 

```go
func maxSubArray(nums []int) int {
    // maxSum 初始化为第一个元素（不能初始化为 0，因为数组元素可能全是负数）
    maxSum := nums[0]
    pre := 0

    for _, x := range nums {
        // 核心转移逻辑：
        // 如果 pre + x 比 x 本身还小（即 pre < 0），那就抛弃前面的 pre，从 x 重新开始
        if pre + x > x {
            pre = pre + x
        } else {
            pre = x
        }

        // 另一种更简洁的数学写法：pre = max(pre + x, x)

        // 更新全局最大值
        if pre > maxSum {
            maxSum = pre
        }
    }

    return maxSum
}
```

- **`x`**：当前遍历到的**元素具体的值**。

func maxSubArray(nums []int) int {
    f := make([]int, len(nums))
    f[0] = nums[0]
    for i := 1; i < len(nums); i++ {
        f[i] = max(f[i-1], 0) + nums[i]
    }
    return slices.Max(f)
}

# Python 解法

### 写法一: 动态规划数组版

```python 
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        for i in range(1, len(nums)):
          # max(nums[i - 1], 0) 表示：如果前面的和大于0，就加上；如果是负数，就加上0（即抛弃前面的）
            nums[i] += max(nums[i - 1], 0)
        return max(nums)

```

这段 Python 代码是 LeetCode 53 题（最大子数组和）中**最省空间、最巧妙**的解法之一（也叫**原地修改的动态规划**）。

它直接把原数组 `nums` 当成了动态规划的 DP 数组，**没有占用任何额外内存空间**。
$$
\text{nums}[i] = \text{nums}[i] + \max(\text{nums}[i-1], 0)
$$


`i in raneg (1, len(nums))` **`nums[0]` 本身就是它自己的基准起点**，它没有“前一个数”可以用来比较。

动态规划（DP）需要一个**初始状态 (Base Case)**：

- 数组的第一位 `nums[0]`，左边没有任何数字可以跟它拼成更长的子数组。
- 无论 `nums[0]` 是正数还是负数，**以 `nums[0]` 结尾的最大连续子数组和，就只能是它自己**。
- 所以 `nums[0]` 不需要任何计算，直接从 **第二个数（索引 `1`）** 开始往后推导计算即可。



### 写法二: 极简空间优化版（推荐，面试常用）

```python 
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        max_sum = nums[0]  # 全局最大和（初始化为第一个元素，防止全负数情况）
        pre = 0            # 记录当前连续子数组的和

        for x in nums: # 直接遍历元素（最推荐，最简洁）
            # 如果 pre + x 比 x 本身还小（说明 pre < 0），那就抛弃前面的，从 x 重新开始 - 二选一
            pre = max(pre + x, x)
            # 更新全局最大和
            max_sum = max(max_sum, pre)

        return max_sum
```

`pre` 记录的是“以当前数字结尾的累计和”**，它是**会起伏波动的（比如后来又亏钱了，`pre` 就会变小）。

为了不丢失曾经达到过的最好成绩，我们需要一个“历史记录仪” `max_sum`

#### 1. 为什么 `max_sum = nums[0]`？

**因为题目要求：子数组“最少包含一个元素”，结果不能是空的！**

如果数组里**全都是负数**（比如 `nums = [-5, -2, -8]`）：

- 最大子数组和应该是 **`-2`**。
- 如果把 `max_sum` 错误地初始化为 `0`： 在后期的比较 `max_sum = max(0, -2)` 时，系统就会误以为答案是 `0`（相当于选了一个空子数组）。
- **所以：** 把 `max_sum` 初始设定为数组里的第一个数 `nums[0]`，是最安全的做法，能完美兼容“全负数数组”的情况。

#### 2. 为什么 `pre = 0`？

`pre` 代表的是“在加当前数字之前，前面凑出来的累加和”。
