# 56. [合并区间](https://leetcode.cn/problems/merge-intervals/?envType=study-plan-v2&envId=top-100-liked)

**按照每个区间的起始位置（左端点）从小到大进行排序**，问题就会变得很清晰。

排序后，所有区间按照左端点依次排列：

1. 我们维护一个结果数组 `merged`，首先将第一个区间直接放入 `merged` 中。
2. 从第二个区间开始遍历当前区间 `interval`：
   - **情况 A（不重叠）：** 如果当前区间的左端点 `interval[0]` **大于** `merged` 中最后一个区间的右端点 `last[1]`，说明两者完全分离，直接将当前区间加入 `merged`。
   - **情况 B（有重叠）：** 如果当前区间的左端点 `interval[0]` **小于等于** `merged` 中最后一个区间的右端点 `last[1]`，说明有重叠。此时我们只需要**更新 `merged` 中最后一个区间的右端点**为两者右端点的最大值：`last[1] = max(last[1], interval[1])`。

### 第一句：`intervals.sort(key=lambda x: x[0])`

**作用：** 按照每个区间的**起点（左端点 `x[0]`）** 从小到大升序排序。

- **原理：**
  - `key=lambda x: x[0]` 是 Python 的匿名函数语法，意思是“排序时只看每个区间的第 0 项（起点）”。

### 第二句与第三句：`if not merged or merged[-1][1] < interval[0]: merged.append(interval)`

这部分用于判断“当前这个区间，是否无法与前一个区间重叠”。如果无法重叠，就只能把它当成一个全新的区间存入结果集。

这句话拆成两个判断条件（用 `or` 连接）：

#### 1. `not merged`

- **含义：** 判断结果数组 `merged` 是不是空的。
- **作用：** 刚开始处理第一个区间时，`merged` 里面什么都没有。我们不能跟“上一个区间”比较，所以直接把第一个区间推进 `merged` 数组里，作为后续对比的基准。

#### 2. `merged[-1][1] < interval[0]`

这是**判断无重叠**的核心算式，我们拆开看符号：

- `merged[-1]`：结果数组中的**最后一个区间**（即上一个已经处理好的区间）。
- `merged[-1][1]`：上一个区间的**终点（右端点）**。
- `interval[0]`：当前正准备处理的区间的**起点（左端点）**。
- **逻辑含义：** 如果**上一个区间的结束时间** < **当前区间的开始时间**，说明它们之间**有空隙，完全断开了**

`merged[-1][1]` 是 Python 访问二维列表中元素的一种语法，可以拆成两部分来看：**`merged[-1]`** 和 **`[1]`**。

简单来说：**它代表“结果数组中，最后一个区间的右端点（结束时间）”。**



> 变成二维列表

```python
intervals = [[1, 3], [2, 6], [8, 10]]  # 这是二维列表
```

当你要定位到表格中的某个具体数字时，需要**双重定位**：

1. **第一个括号 `[-1]`（选行）：** 找到外层列表的最后一个元素（即最后一行，假设是 `[8, 10]`）。
2. **第二个括号 `[1]`（选列）：** 找到这行列表里的第 2 个数字（索引为 1 的列，即 `10`）。

```python
merged = [[1, 3], [2, 6], [8, 10]]

# 第一步：merged[-1] 得到的是一个一维列表 [8, 10]
last_interval = merged[-1] 

# 第二步：last_interval[1] 得到的是数字 10
end_point = last_interval[1]

# 合起来简写就是：
end_point = merged[-1][1]  # 结果是 10
```



### 答案

```python 
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort(key=lambda x: x[0])

        merged = []
        for interval in intervals:
            # 如果列表为空，或者当前区间与上一区间不重合，直接添加
            if not merged or merged[-1][1] < interval[0]:
                merged.append(interval)
            else:
                # 否则的话，我们就可以与上一区间进行合并
                # interval[1] 就是当前新区间的终点。
                merged[-1][1] = max(merged[-1][1], interval[1])

        return merged
```
