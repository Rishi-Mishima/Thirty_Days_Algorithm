## 二分查找区间

二分查找有三种常见区间写法，核心区别在于边界初始值和更新方式：

| **区间类型**             | **格式**        | **初始设置**                       | **while 条件**     | **边界更新**                       |
| ------------------------ | --------------- | ---------------------------------- | ------------------ | ---------------------------------- |
| **闭区间**（代码中用的） | `[left, right]` | `left = 0` `right = len(nums) - 1` | `left <= right`    | `left = mid + 1` `right = mid - 1` |
| **左闭右开**             | `[left, right)` | `left = 0` `right = len(nums)`     | `left < right`     | `left = mid + 1` `right = mid`     |
| **开区间**               | `(left, right)` | `left = -1` `right = len(nums)`    | `left + 1 < right` |                                    |

> **建议：** 在做力扣题时，**闭区间写法 `[left, right]`** 是最推荐、最不容易写错（不容易死循环或漏掉元素）的形式。



## 35. [搜索插入位置](https://leetcode.cn/problems/search-insert-position/description/?envType=study-plan-v2&envId=top-100-liked) 

返回 *nums* 中的第一个（最左边的）**大于或等于** *target* 的数的下标。如果所有数都小于 *target*，返回 *nums* 的长度。

### 解法一: 库函数

```python 
import bisect

class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        return bisect.bisect_left(nums, target)
```

#### `bisetc` 

`bisect_left` 和 `bisect_right` 的核心区别在于**处理序列中存在重复元素时返回的插入位置不同**。 [[1](https://agent.csdn.net/6a4f70ce10ee7a33f28b89b7.html)]

核心区别

- **`bisect_left(a, x)`**：返回目标值 `x` 在有序序列 `a` 中的**最左侧**插入位置。如果 `x` 已经存在于列表中，返回第一个 `x` 的左侧索引位置（即所有等于 `x` 的元素的最左边）。 [[1](https://zhuanlan.zhihu.com/p/24538905792), [2](https://docs.python.org/zh-cn/3.7/library/bisect.html)]
- **`bisect_right(a, x)`**：返回目标值 `x` 在有序序列 `a` 中的**最右侧**插入位置（等同于简写函数 `bisect`）。如果 `x` 已经存在于列表中，返回最后一个 `x` 的右侧索引位置（即所有等于 `x` 的元素的最右边加一）。

假设有一个有序列表 `a = [1, 2, 2, 2, 3]`，我们要查找元素 `2` 的插入点：

- `bisect_left(a, 2)` 返回 `1`。因为第一个 `2` 的左边索引是 `1`（即 `a[1] == 2`）。
- `bisect_right(a, 2)` 返回 `4`。因为最后一个 `2` 的右边索引是 `4`（即 `a[3] == 2`，右侧紧邻的位置是 `4`）。

如果查找一个**不存在**的元素，比如 `2.5`：

- `bisect_left(a, 2.5)` 和 `bisect_right(a, 2.5)` 都返回 `4`（它们都会指向应该插入 `2.5` 从而保持列表有序的同一个正确位置）。



### 解法二: 二分查找

#### 返回left 

```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while(left <= right){
            int middle = left + (right - left)/2;
            if (nums[middle]< target){
                left = middle + 1;    
            } else  {
                right = middle -1;            
            }                 
        }
     return left;
    }
}
```



#### 返回middle & right

```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        if(nums.length == 0 || nums == null) return 0; 

        int left = 0; 
        int right = nums.length - 1; 

        while(left <= right){
            int middle = left + (right - left) /2 ; 
            if(nums[middle] < target){
                left = middle + 1; 
            }else if(nums[middle] > target){
                right = middle - 1; 
            }else{
                return middle; 
            }
        }
        return right + 1;
    }
}
```

**`return middle` 为什么可以？**

因为题目明确说了数组**无重复元素**，所以一旦 `nums[middle] == target`，`middle` 就是唯一且正确的位置，直接返回即可。

**`return right + 1` 为什么也对？**

当循环结束（`left > right`）时，说明 target 不在数组中。此时 `right` 指向的是最后一个 < target 的元素，所以插入位置就是 `right + 1`。



#### python 

```python 
class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums)
        while left < right:
            mid = (left + right) // 2
            if nums[mid] >= target:
                right = mid
            else:
                left = mid + 1
        return left
```



#### 注意点

1. `len(nums)` 为什么不用-1 

这取决于选择的**搜索区间**风格，两种都正确，但写法不同：

**风格一：左闭右开 `[left, right)`** — `right = len(nums)`

```python 
left, right = 0, len(nums)
while left < right:        # 注意是 <
    mid = (left + right) // 2
    if nums[mid] >= target:
        right = mid         # mid 还在区间内
    else:
        left = mid + 1
```

**风格二：左闭右闭 `[left, right]`** — `right = len(nums) - 1`

```python
left, right = 0, len(nums) - 1
while left <= right:       # 注意是 <=
    mid = (left + right) // 2
    if nums[mid] >= target:
        right = mid - 1     # mid 排除出区间
    else:
        left = mid + 1
```

| `right = len(nums)` | `right = len(nums) - 1` |                      |
| ------------------- | ----------------------- | -------------------- |
| 区间                | `[left, right)` 右开    | `[left, right]` 右闭 |
| 循环条件            | `left < right`          | `left <= right`      |
| 缩小区间            | `right = mid`           | `right = mid - 1`    |

关键点：**右开时 `right` 不在搜索范围内**，所以缩小时可以直接 `right = mid`（mid 已经被 `<` 排除了）；**右闭时 `right` 在范围内**，所以必须 `right = mid - 1` 来排除 mid。



## 74. [搜索二维矩阵](https://leetcode.cn/problems/search-a-2d-matrix/description/?envType=study-plan-v2&envId=top-100-liked) 

**将一个二维矩阵（行数为 m，列数为 n）按行拼接（摊平）成一个一维数组时，元素在一维数组中的下标 i，与它在二维矩阵中的位置（行号 r、列号 c）存在一一对应的数学映射关系。**

你不需要在内存中创建一个真正的一维数组，只需要通过**除法**和**取余**，就能瞬间算出一个一维下标对应在矩阵里的什么位置。

- **求行号（整除）：** 每满 $n$ 个元素，就会换到下一行。所以下标 $i$ 里面包含了多少个完整的 $n$，就说明它前面已经排满了多少行，也就是它的**当前行号**。

- **求列号（取余）：** 除去前面整行填满的元素后，还剩下几个元素？剩下的这个数（余数），就是它在**当前行里的偏移量**，也就是**列号**。

矩阵有 `m` 行 `n` 列，展平后一维下标范围是：

```
有效下标:   0,  1,  2,  ... ,  m*n - 1
                         ↑ 最后一个元素
                         
left = -1        →  在第一个有效下标 0 的"左边外面"
right = m * n    →  在最后一个有效下标 m*n-1 的"右边外面"

搜索区间:  (-1, m*n)   ← 开区间，不含两端
有效元素:   0, 1, 2, ..., m*n-1   ← 全部包含在内
```



### 解法一: 一次二分查找

```python 
left, right = -1, m * n      # 开区间，不包含边界
while left + 1 < right:       # 区间内至少还有一个元素
    mid = (left + right) // 2
    x = matrix[mid // n][mid % n]   # 一维下标转二维坐标
    if x == target:
        return True
    if x < target:
        left = mid            # target 在右半部分
    else:
        right = mid           # target 在左半部分
return False                   # 没找到
```



### 注意点

#### python取中点

> 在 Python 中，`//` 表示 **整除（Floor Division，向下取整除法）**。

`(left + right) // 2` 的作用是：**计算 `left` 和 `right` 的平均值，并且强制把结果保留为整数（向下取整）。**

Python 中有两种除法运算符：

- **单斜杠 `/`（普通除法）：** 计算结果永远是 **浮点数（小数）**。

  - 例如：`7 / 2` 结果是 `3.5`
  - 如果在二分查找中使用 `(0 + 7) / 2`，得到 `3.5`。但数组的下标（索引）必须是**整数**，使用 `matrix[3.5]` 会直接报错 `TypeError`。

- **双斜杠 `//`（整除 / 地板除）：** 计算结果会**舍去小数部分，向下取整**，得到一个 **整数**。

  - 例如：`7 // 2` 结果是 `3`
  - `(0 + 7) // 2` 得到 `3`，这是一个合法的数组索引。

  

#### 开区间

这里用的是**开区间** `(left, right)`：

- `left = -1`：左边界在数组"左边外面"
- `right = m * n`：右边界在数组"右边外面"
- 循环条件 `left + 1 < right`：当左右边界相邻时停止，说明区间内已无元素



#### 转一维数组

**`x = matrix[mid // n][mid % n]`**

将一维下标 `mid` 转换为二维坐标，取出对应的元素值：

- `mid // n` → 行号（整除取商）
- `mid % n` → 列号（取余数）

例如 `mid = 5, n = 4`：`5 // 4 = 1`（第 1 行），`5 % 4 = 1`（第 1 列），即 `matrix[1][1]`。

> 简单来说：**取中间位置 → 转成二维坐标 → 拿到元素值**，然后和 `target` 比较来决定缩小区间的方向。



#### 二分核心

每次取到中间元素 `x` 后，和 `target` 比较，决定下一步怎么缩小搜索范围。

```python
if x < target:
    left = mid           # target 在右半边
```

应用代码

`x` 比目标小，由于数组是递增的，`target` 只可能在 `mid` 的**右边**。把左边界移到 `mid`，下一轮搜索 `(mid, right)` 这个区间。

```python 
return False             # 循环结束还没找到，说明不存在
```





## 34. [在排序数组中查找元素的第一个和最后一个位置](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/description/?envType=study-plan-v2&envId=top-100-liked) 

> **核心直觉：** 因为数组已经排好序，且要求 $O(\log n)$ 复杂度，这明确提示我们必须使用 **二分查找**。普通的二分查找只要找到 `target` 就直接返回下标了，但本题由于有重复元素，找到一个 `target` 后，我们需要继续分别寻找它的**左边界**（第一个位置）和**右边界**（最后一个位置）。

### 解题思路（两次二分）

我们可以拆解为两个独立的二分查找过程：

1. **找左边界**：找到数组中**第一个**等于 `target` 的位置。
2. **找右边界**：找到数组中**最后一个**等于 `target` 的位置。

1. 寻找左边界逻辑

当 `nums[mid] == target` 时，我们**不立刻返回**，而是继续向左缩小区间（`right = mid - 1`），看左边还有没有相同的 `target`，同时用一个变量记录下当前遇到的最靠左的下标。

2. 寻找右边界逻辑

当 `nums[mid] == target` 时，我们同样**不立刻返回**，而是继续向右缩小区间（`left = mid + 1`），看右边还有没有相同的 `target`，同时记录最靠右的下标。



### 解法一:  `[left, right]` 

```python 
class Solution:
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        def findLeft(nums, target):
            left, right = 0, len(nums) - 1
            left_idx = -1
            while left <= right:
                mid = (left + right) // 2
                if nums[mid] == target:
                    left_idx = mid    # 记录当前找到的位置
                    right = mid - 1   # 继续往左边找，看还有没有
                elif nums[mid] < target:
                    left = mid + 1
                else:
                    right = mid - 1
            return left_idx

        def findRight(nums, target):
            left, right = 0, len(nums) - 1
            right_idx = -1
            while left <= right:
                mid = (left + right) // 2
                if nums[mid] == target:
                    right_idx = mid   # 记录当前找到的位置
                    left = mid + 1    # 继续往右边找，看还有没有
                elif nums[mid] < target:
                    left = mid + 1
                else:
                    right = mid - 1
            return right_idx

        # 分别查找左右边界
        start = findLeft(nums, target)
        end = findRight(nums, target)
        
        return [start, end]
```

### 注意点

#### elif

`elif`（即 else if 的缩写）的执行逻辑遵循**严格的前置排他原则**：

- **只有前面的 `if` 条件判断为假（不满足）时，程序才会去检查 `elif` 的条件。**
- 如果前面的 `if` 已经满足了，程序就会**直接跳过**后面所有的 `elif` 和 `else`，不再做任何多余的判断。

```python
if nums[mid] == target:
    left_idx = mid
    right = mid - 1     
elif nums[mid] < target:
    left = mid + 1      
else:
    right = mid - 1    
```



## 33. [搜索旋转排序数组](https://leetcode.cn/problems/search-in-rotated-sorted-array/?envType=study-plan-v2&envId=top-100-liked)

### 思路

关键破局点在于：**如果我们取数组的中点 `mid`，将数组一分为二，那么左半边和右半边里，必然至少有一半是严格递增（有序）的**

我们依然维护两个指针 `left` 和 `right`：

1. 计算中点 `mid = (left + right) // 2`。
2. 如果 `nums[mid] == target`，直接找到，返回 `mid`。
3. **判断哪半边是有序的**：
   - 如果 `nums[left] <= nums[mid]` -->  **左半边有序**。
     - 判断 `target` 在不在左半边的区间内（即 `nums[left] <= target < nums[mid]`）？
     - 如果**在** --> 把搜索范围缩小到左半边（`right = mid - 1`）。
     - 如果**不在** --> 去右半边找（`left = mid + 1`）。
   - 否则（`nums[left] > nums[mid]`） --> **右半边有序**。
     - 判断 `target` 在不在右半边的区间内（即 `nums[mid] < target <= nums[right]`）？
     - 如果**在** --> 把搜索范围缩小到右半边（`left = mid + 1`）。
     - 如果**不在** --> 去左半边找（`right = mid - 1`）。

```python 
class Solution:
    def search(self, nums: list[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        
        while left <= right:
            mid = (left + right) // 2
            
            # 1. 刚好在中点找到目标值
            if nums[mid] == target:
                return mid
            
            # 2. 判断左半边是否有序
            if nums[left] <= nums[mid]:
                # 目标值在左半边的有序区间内
                if nums[left] <= target < nums[mid]:
                    right = mid - 1
                else:
                    left = mid + 1
            # 3. 否则，右半边必然有序
            else:
                # 目标值在右半边的有序区间内
                if nums[mid] < target <= nums[right]:
                    left = mid + 1
                else:
                    right = mid - 1
                    
        return -1
```



###
