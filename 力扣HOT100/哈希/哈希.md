## 1. [两数之和](https://leetcode.cn/problems/two-sum/description/?envType=study-plan-v2&envId=top-100-liked)

### 解法一: 暴力枚举 (brute force)

双循环

```python 
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        n = len(nums)
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] + nums[j] == target:
                    return [i, j]

        ## 兜底返回 - 返回一个空数组
        return []
```



### 解法二: 哈希表

- **核心数学转化**：

  - 找到 target - A = B 

- **算法逻辑**：

  用一个哈希表（Python 中的字典 `dict`）来做记录，保存 **`{数值: 下标}`** 的映射。

  遍历数组中的每个数字 `num` 和它的下标 `i`：

  1. 计算匹配需要的“另一半”：`complement = target - num`。
  2. 检查 `complement` 是否已经在哈希表里：
     - **如果在**：说明之前遇到过这个数！直接返回 `[哈希表中 complement 的下标, i]`。
     - **如果不在**：把当前的 `num` 和它的下标 `i` 存入哈希表，继续看下一个数。

```python 
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        seen = {}  # 用来记录已遍历过的 {数值: 下标}
        
        for i, num in enumerate(nums):
            complement = target - num  # 计算需要的另一个数
            
            # 如果另一个数已经在哈希表里，直接返回答案
            if complement in seen:
                return [seen[complement], i]
            
            # 否则把当前数和下标记录下来
            seen[num] = i
            
        return []
```



#### 注意点

##### `enumerate(nums)` 

>  同时拿到“下标”和“数值”

在普通的 `for num in nums:` 循环中，你只能拿到数组里的元素，拿不到元素的下标；如果用 `for i in range(len(nums)):`，你只能拿到下标，还得写 `nums[i]` 去取数值。

`for i, num in enumerate(nums)` 

`enumerate()` 可以把两者结合起来，每次循环同时返回 **`(下标, 数值)`**

>  `enumerate()` 返回的顺序是**固定**的：**`(下标, 元素数值)`**。



##### 字典 / HashMap 

创建dict

- {}
- hashmap = dict()

> `{}` 是 Python 的**字面量语法（Literal Syntax）**，而 `dict()` 是**调用内置构造函数**。

{}因此更快

- **定义与插入 (`seen[num] = i`)**：

把 `num` 作为 Key，`i` 作为 Value 存进去。

比如 `seen[2] = 0` 表示：“数字 2 存进去了，它的位置在下标 0”。

- **查找 Key 是否存在 (`if complement in seen:`)**：

`in` 关键字可以极快（O(1) 时间复杂度）地检查某个键（Key）是不是在字典里。注意：它检查的是 **Key**，而不是 Value。

**根据 Key 获取 Value (`seen[complement]`)**：

就像数组用下标取值 `arr[i]` 一样，字典用 Key 取对应的 Value。

如果 `seen` 是 `{2: 0}`，那么 `seen[2]` 的结果就是 `0`。



##### 返回[seen(complement), i]

`i` 是**当前遍历到的这个数字在 `nums` 数组里的下标**。

因为我们在循环里写了 `for i, num in enumerate(nums):`：

- `num` 代表当前的数字（比如 `7`）。
- `i` 代表这个数字所在的位置索引（比如第 `1` 个位置）。

`seen[complement]` 是什么？

`seen[complement]` 是**之前存进去的那个“匹配数字”的下标**。

- `complement` 是我们需要的“另一半数字”（即 `target - num`）。
- 字典 `seen` 里存的格式是 `{数字 : 下标}`。
- 所以 `seen[complement]` 就是取出“另一半数字”在数组里的下标。

> **`seen[complement]`**：先找到的那个数字的下标（左边的位置）。
>
> **`i`**：刚刚找到的这个数字的下标（右边的位置）。
