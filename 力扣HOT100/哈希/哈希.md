## 1. [两数之和](https://leetcode.cn/problems/two-sum/description/?envType=study-plan-v2&envId=top-100-liked)

### 解法一: 暴力枚举 (brute force)

双循环

```python 
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        n = len(nums)
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] + nums[j] == target:
                    return [i, j]

        ## 兜底返回 - 返回一个空数组
        return []
```



### 解法二: 哈希表

- **核心数学转化**：

  - 找到 target - A = B 

- **算法逻辑**：

  用一个哈希表（Python 中的字典 `dict`）来做记录，保存 **`{数值: 下标}`** 的映射。

  遍历数组中的每个数字 `num` 和它的下标 `i`：

  1. 计算匹配需要的“另一半”：`complement = target - num`。
  2. 检查 `complement` 是否已经在哈希表里：
     - **如果在**：说明之前遇到过这个数！直接返回 `[哈希表中 complement 的下标, i]`。
     - **如果不在**：把当前的 `num` 和它的下标 `i` 存入哈希表，继续看下一个数。

```python 
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        seen = {}  # 用来记录已遍历过的 {数值: 下标}
        
        for i, num in enumerate(nums):
            complement = target - num  # 计算需要的另一个数
            
            # 如果另一个数已经在哈希表里，直接返回答案
            if complement in seen:
                return [seen[complement], i]
            
            # 否则把当前数和下标记录下来
            seen[num] = i
            
        return []
```



#### 注意点

##### `enumerate(nums)` 

>  同时拿到“下标”和“数值”

在普通的 `for num in nums:` 循环中，你只能拿到数组里的元素，拿不到元素的下标；如果用 `for i in range(len(nums)):`，你只能拿到下标，还得写 `nums[i]` 去取数值。

`for i, num in enumerate(nums)` 

`enumerate()` 可以把两者结合起来，每次循环同时返回 **`(下标, 数值)`**

>  `enumerate()` 返回的顺序是**固定**的：**`(下标, 元素数值)`**。



##### 字典 / HashMap 

创建dict

- {}
- hashmap = dict()

> `{}` 是 Python 的**字面量语法（Literal Syntax）**，而 `dict()` 是**调用内置构造函数**。

{}因此更快

- **定义与插入 (`seen[num] = i`)**：

把 `num` 作为 Key，`i` 作为 Value 存进去。

比如 `seen[2] = 0` 表示：“数字 2 存进去了，它的位置在下标 0”。

- **查找 Key 是否存在 (`if complement in seen:`)**：

`in` 关键字可以极快（O(1) 时间复杂度）地检查某个键（Key）是不是在字典里。注意：它检查的是 **Key**，而不是 Value。

**根据 Key 获取 Value (`seen[complement]`)**：

就像数组用下标取值 `arr[i]` 一样，字典用 Key 取对应的 Value。

如果 `seen` 是 `{2: 0}`，那么 `seen[2]` 的结果就是 `0`。



##### 返回[seen(complement), i]

`i` 是**当前遍历到的这个数字在 `nums` 数组里的下标**。

因为我们在循环里写了 `for i, num in enumerate(nums):`：

- `num` 代表当前的数字（比如 `7`）。
- `i` 代表这个数字所在的位置索引（比如第 `1` 个位置）。

`seen[complement]` 是什么？

`seen[complement]` 是**之前存进去的那个“匹配数字”的下标**。

- `complement` 是我们需要的“另一半数字”（即 `target - num`）。
- 字典 `seen` 里存的格式是 `{数字 : 下标}`。
- 所以 `seen[complement]` 就是取出“另一半数字”在数组里的下标。

> **`seen[complement]`**：先找到的那个数字的下标（左边的位置）。
>
> **`i`**：刚刚找到的这个数字的下标（右边的位置）。



## 49. [字母异位词分组](https://leetcode.cn/problems/group-anagrams/description/?envType=study-plan-v2&envId=top-100-liked)

### 解法一: 排序

java

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap <String, List<String>>(); 

        for (String str: strs){
            char[] arr = str.toCharArray(); 
            Arrays.sort(arr); 

            // 将排序后的字符数组重新组装成字符串 "aet"，作为分组标识。
            String key = new String(arr); 

            // 检查 map 中是否已有 "aet" 这个 Key。如果有就取出对应的列表；如果没有，则返回一个全新的空列表 new ArrayList<String>()。
            List<String> list = map.getOrDefault(key, new ArrayList<>()); 

            //把当前原始单词（如 "tea"）加进列表中。
            list.add(str); 

            //将更新后的列表放回 map。
            map.put(key, list); 

        }

        // map.values() 会取出哈希表中所有的列表值（即分组好的结果）。
        //利用 new ArrayList<>(...) 将其直接构造并返回目标要求的 List<List<String>> 格式
        return new ArrayList<List<String>>(map.values()); 
    }
}
```



#### JAVA注意点

1. **`char[] arr = str.toCharArray()`** — 将字符串拆成字符数组，因为 Java 中字符串不能直接排序。
2. **`Arrays.sort(arr)`** — 对字符数组按字母顺序排序，这是生成统一 Key 的关键。
3. **`String key = new String(arr)`** — 排序后的字符数组重新拼成字符串，作为 HashMap 的 Key。
4. **`map.getOrDefault(key, new ArrayList<>())`** — 如果 Key 已存在，取出对应列表；不存在则创建新空列表。
5. **`list.add(str)`** — 把**原始单词**（不是排序后的）加入列表。
6. **`return new ArrayList<>(map.values())`** — 取出所有分组列表，包装成要求的返回类型。



python 

由于互为字母异位词的两个字符串包含的字母相同，因此对两个字符串分别进行排序之后得到的字符串一定是相同的，故可以将排序之后的字符串作为哈希表的键。

```python 
from collections import defaultdict

class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        # 创建一个默认值为 list 的字典
        # 这样当 Key 第一次出现时，会自动初始化为一个空列表 []
        anagram_map = defaultdict(list)
        
        for s in strs:
            # 1. 对字符串进行字符排序，作为哈希表的 Key
            # sorted(s) 返回的是字符列表 ['a', 'e', 't']，需要用 "".join() 拼回字符串
            sorted_key = "".join(sorted(s))
            
            # 2. 将原始字符串 s 追加到对应 Key 的列表中
            anagram_map[sorted_key].append(s)
            
        # 3. 返回字典中所有的 Value 组合
        return list(anagram_map.values())
```



#### Python注意点

##### 普通字典 vs `defaultdict`

普通字典 (`{}`)

如果你想把元素装进列表里，用普通字典写代码会很繁琐，因为你必须**手动检查 Key 在不在**：

```python
d = {}
key = "fruit"

# 必须先判断 Key 在不在，不在就要手动建一个空列表
if key not in d:
    d[key] = []
    
d[key].append("apple")  # 结果：{'fruit': ['apple']}
```

> 如果不写 `if` 判断，直接执行 `d["fruit"].append("apple")`，Python 会直接抛出 `KeyError` 报错！



`defaultdict(list)`

如果用 `defaultdict(list)`，完全不需要写 `if` 判断，直接追加即可：

```python 
from collections import defaultdict

# 告诉它：只要遇到新 Key，默认值就调用 list() 生成一个空列表 []
d = defaultdict(list)

# 直接 append！Key "fruit" 之前不存在？没关系，它会自动先建一个 [] 再 append
d["fruit"].append("apple")  # 结果：defaultdict(<class 'list'>, {'fruit': ['apple']})
```



#####  `key = "".join(sorted(st))` 写法

—— 把列表拼回字符串

`join()` 是 Python 字符串的方法，用于将列表里的多个字符串元素连接成一个新的字符串。

- **语法**：`"连接符".join(列表)`
- 如果连接符是 `""`（空字符串），就代表**无缝拼接**。



### 解法二: 计数

相比于之前的“排序法”，这种写法巧妙地利用了**26 个英文字母的出现频次**作为字典的 Key，将时间复杂度从 O(n * k * logK) 降低到了 O(n * k), n 是字符串个数，k 是字符串最大长度）。

> 我们可以用一个长度为 26 的列表 `counts` 记录每个小写字母的出现次数。只要两个词的 `counts` 数组一模一样，它们就是字母异位词！

由于字母相同，因此**两个字符串中的相同字母出现的次数一定是相同的**，故可以将每个字母出现的次数使用字符串表示，作为哈希表的Key。

由于字符串只包含小写字母，因此对于每个字符串，可以使用长度为 26 的数组记录每个字母出现的次数。

```python 
class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        # 1. 创建默认值为 list 的哈希表
        mp = collections.defaultdict(list)

        for st in strs:
            # 2. 初始化一个长度为 26、初始值全为 0 的列表
            counts = [0] * 26
            
            # 3. 统计当前字符串中每个字母的出现次数
            for ch in st:
                # ord(ch) - ord("a") 计算字母对应的相对位置 (0 ~ 25)
                # 例如：ord('a') - ord('a') = 0，ord('b') - ord('a') = 1
                counts[ord(ch) - ord("a")] += 1
            
            # 4. 关键：将 list 转为 tuple 作为字典的 Key
            # 列表 [1, 0, 0...] 是可变的，不能做 Key；元组 (1, 0, 0...) 是不可变的，可以做 Key
            mp[tuple(counts)].append(st)
        
        # 5. 返回所有分组后的列表集合
        return list(mp.values())
```

1. **`mp = collections.defaultdict(list)`**
   创建一个默认值为空列表的字典，省去判断键是否存在的步骤。
2. **`counts = [0] * 26`**
   为每个字符串创建一个长度为 26 的计数数组，分别对应 `a` ~ `z`。
3. **`counts[ord(ch) - ord("a")] += 1`**
   遍历字符串中每个字符，`ord(ch) - ord("a")` 将字符映射到 `0~25` 的下标，对应位置计数 +1。
   例如 `"eat"` → `[1,0,0,0,1,0,...,0,1,0,...]`（e、a、t 各出现 1 次）。
4. **`mp[tuple(counts)].append(st)`**
   **关键点**：Python 中 `list` 不可哈希，不能作为字典的键；`tuple` 是不可变类型，可以哈希。所以将计数数组转成 `tuple` 作为键。
   异位词（如 `"eat"` 和 `"tea"`）的计数数组完全相同，因此会被归入同一个键下。
5. **`return list(mp.values())`**
   字典的所有值就是分组结果，转成列表返回。

① `[0] * 26` —— 快速创建定长数组

Python 中用 `[初始值] * 长度` 可以快速生成指定长度的列表。`[0] * 26` 相当于建了一个包含 26 个 `0` 的列表，对应 `'a'` 到 `'z'`。

② `ord(ch) - ord("a")` —— 计算字母下标

- `ord()` 函数返回字符的 ASCII 码值。例如 `ord('a')` 是 `97`，`ord('b')` 是 `98`。
- `ord('c') - ord('a')` -->  `99 - 97 = 2`，对应 `counts` 数组里的下标 `2`（第3个位置）。

③ `tuple(counts)` —— 不可变类型转换（必须点）

在 Python 中，字典的 Key **必须是不可变类型（Hashable）**：

- ❌ **`list`（列表）** 是可变对象，写 `mp[counts]` 会抛出 `TypeError: unhashable type: 'list'`。
- ✅ **`tuple`（元组）** 是不可变对象，写 `mp[tuple(counts)]` 可以合法作为哈希表的 Key。
